# mygo desktop, slice 1 (approval core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The native mygo app does what the Electron app's approval core does:
- create a vault, unlock and lock, the idle and soft locks, and the soft-lock screen with "Stop auto-allow and lock";
- a read-only host list with search, and the store-error banner;
- the AI requests column with every guard, the Auto-allowed feed and "Stop all auto-allow";
- hub restart screens;
- the tray pending count and notifications.

Each piece carries the Electron renderer's rules and texts, with Go tests for each.

**Architecture:**
- **Packages.** Three layers, each a package under `app/`:
  - `hubapi` holds the typed UI-door calls and events.
  - `model` holds the renderer's pure rules, ported one-to-one with their vitest cases as table tests.
  - `view` holds the controller (`App`, the port of `App.tsx`) and the native screens.
- **Event path.** Hub notifications reach `App.Note` on the main thread through `Window.Update`. `App` only calls `status` without a user action. Every other call follows a click, key or screen change.
- **Tray and notifications.** They sit behind a small `view.Shell` interface. `main.go` implements it with mygo; tests fake it.

**Tech Stack:** Go 1.27.1 (`app/` module), mygo `ui` (fork commit `25387f1`), the existing `door`, `hubproc`, `termconn` and `hubtest` packages, and `sshgate hub` (UI door protocol 12, MCP door).

## Global Constraints

- **Branch and scope.**
  - Work on branch `feat/mygo-slice1`. It is based on `feat/mygo-desktop` (PR #23).
  - Edit only `app/`, and the plan's own docs.
  - `internal/`, `cmd/sshgate`, `desktop/` and the protocol are unchanged.
- **Wire.** UI door protocol 12, newline JSON-RPC.
  - Hub errors arrive as `*door.Error`, whose `Error()` is the hub's message verbatim. Show it unchanged.
  - Compare errors by message text, as `scratchpad/s1/protocol.md` §5 lists them.
- **Activity rule.** `App` calls nothing on a timer. `App` calls only `status` in response to a hub notification or a hub state change.
  - These calls run once per screen transition into `ready`: `servers`, plus one `pending` seed.
  - These calls run only after a click, a key or a submit: `unlock`, `lock`, `vault.create`, `decide`, `denyAll` and `servers.setAutoAllow`.
- **Guards.**
  - `AllowDelay = 500 ms`.
  - Allow and Send to tab are `view.MouseButton`: never focusable, Enter and Space never press them.
  - Deny is the only keyboard action in a request. Enter in its reason field submits Deny.
  - An arriving request never takes the keyboard focus.
  - Deny all is disabled below 2 requests.
- **Verbatim strings.** These must be used character for character:
  - `Unlock vault`, `Master password`, `Unlock`, `Locked after inactivity.`
  - `Open terminals stay connected while locked. AI requests are refused until you unlock.`
  - `AI auto-allow is still running on: ` (followed by the names joined with `, `), `Stop auto-allow and lock`, `Could not stop auto-allow: `
  - `Create your vault`, `The master password encrypts saved passwords and protects the host list.`, `New master password`, `Confirm master password`, `At least 8 characters`, `Both passwords match`, ` (not yet)`
  - `The master password cannot be recovered. If you forget it, this vault cannot be unlocked and its saved passwords are lost.`
  - `These servers from your existing file are kept, with Visible to AI turned off and their host keys unpinned; you'll confirm each key on the next connect.`
  - `Create vault`, `Starting the hub…`, `Hub crashed. Restarting in %d s (attempt %d).`, `The vault will be locked again after the restart. Open terminals will end.`, `The hub stopped`
  - `AI requests`, `Close AI requests`, `Deny all`, `Commands wait for you unless their host is on auto-allow. Enter in a request denies; Allow takes a mouse click.`
  - `Nothing waiting.`, `Could not load pending requests: `, `Reason (optional)`, `Deny`, `Send to tab`, `Allow`, `AI's description · unverified`, `timeout %ds · client %s (unverified)`, `stdin · `, `SUDO`

  - `Lock`, `AI`, `New key`, `Hosts`
- **Untrusted text.** Server-sourced text (server names, host, user, target, description, client, error texts) goes through `model.DisplayText` before `ui.Text`. Commands and stdin are shown through `model.HighlightNonASCII`.

## Review Focus

1. **A seed racing a decision.** A `decided` that arrives while the `pending` seed call is in flight must not bring the request back. A request that arrives during the call must not be hidden. Covered by Task 2 (`TestMergeSeed`) and Task 5 (`TestSeedRacingDecidedDoesNotResurrect`).
2. **Hub restart mid-session.** Every client list must reset, and so must the tray count. A stale Allow must not decide on the new hub. Covered by Task 5 (`TestHubRestartResetsState`) and Task 9 (`TestShellCountResetsOnRestart`).
3. **A request with stdin.** Send to tab is disabled and Allow still works once the delay has passed. Covered by Task 8 (`TestStdinRequestDisablesSendToTabOnly`).
4. **Spoofing text.** Bidi overrides or zero-width characters in a server name, target, description or command are escaped or highlighted, never rendered raw. Covered by Task 2 (`TestDisplayText`) and Task 8 (`TestItemEscapesServerTextAndMarksCommand`).
5. **A status reply racing `autoAllow.off`.** A `status` reply that left before an `autoAllow.off` must not re-add that host to the soft-lock list. Covered by Task 5 (`TestStatusReplyDoesNotReaddDroppedHost`).

## Decisions taken in this plan (controller rulings, on the spec)

- **Send to tab.** In slice 1 it is rendered but always disabled. This keeps the Deny / Send to tab / Allow spacing that guards against a missed click. It becomes real in slice 2 with tabs.
- **Cmd+Shift+A and Esc.** Both move to slice 2. They live in the terminal key handler.
- **Terminal.**
  - A host card opens a single terminal page (the slice-0 terminal), with a "Hosts" button back to the list. The terminal stays alive.
  - Opening another host closes the old terminal off the main thread.
  - The lock screen covers everything while locked, and the terminal stays alive behind it.
  - Tabs, host-key prompts and terminal shortcuts come in slice 2.
- **Deferred to slice 3, per the spec:**
  - per-card "Stop auto-allow", the paused banner (Resume / Stop), the ran-while-locked banner, Settings and the theme switch;
  - the `ranWhileLocked` reply field, which is decoded but not shown yet.
- **Screen readers.** `ui.Button` and `RoleButton` presses from assistive technology still reach Allow, as they do in Electron. This is recorded and not changed.

```go
package hubapi

import (
	"context"
	"encoding/json"

// rec records one call and answers it with a canned JSON result.
type rec struct {
	method string
	params string
	result string
}

func (r *rec) Call(_ context.Context, method string, params, result any) error {
	r.method = method
	b, _ := json.Marshal(params)
	r.params = string(b)
	if result != nil && r.result != "" {
		return json.Unmarshal([]byte(r.result), result)
	}
	return nil
}

func TestCallShapes(t *testing.T) {
	ctx := context.Background()
	for _, tc := range []struct {
		name, method, params string
		call                 func(*Client) error
	}{
		{"lock", "lock", `{}`, func(c *Client) error { return c.Lock(ctx, false) }},
		{"stop and lock", "lock", `{"stopAuto":true}`, func(c *Client) error { return c.Lock(ctx, true) }},
		{"unlock", "unlock", `{"password":"pw"}`, func(c *Client) error { _, err := c.Unlock(ctx, "pw"); return err }},
		{"decide", "decide", `{"id":"abc","outcome":"denied","reason":"no"}`, func(c *Client) error { return c.Decide(ctx, "abc", Denied, "no") }},
```

```go
package hubapi

import "context"

// Caller is the UI door client (door.Client) or a test fake.
type Caller interface {
	Call(ctx context.Context, method string, params, result any) error
}

type Client struct{ c Caller }

func New(c Caller) *Client { return &Client{c: c} }

func (h *Client) Status(ctx context.Context) (Status, error) {
	var s Status
	err := h.c.Call(ctx, "status", nil, &s)
	return s, err
}

func (h *Client) Unlock(ctx context.Context, pw string) (UnlockReply, error) {
	var r UnlockReply
	err := h.c.Call(ctx, "unlock", map[string]string{"password": pw}, &r)
	return r, err
}

// Lock sends {} (a soft lock when a grant is live) or {"stopAuto":true}
// (hard lock, ends every grant); the hub refuses anything else.
func (h *Client) Lock(ctx context.Context, stopAuto bool) error {
	p := map[string]bool{}
	if stopAuto {
		p["stopAuto"] = true
	}
	return h.c.Call(ctx, "lock", p, nil)
}

func (h *Client) Servers(ctx context.Context) ([]Server, error) {
	s := []Server{}
	if err := h.c.Call(ctx, "servers", nil, &s); err != nil {
		return nil, err
	}
	if s == nil {
		s = []Server{}
	}
	return s, nil
}

func (h *Client) Pending(ctx context.Context) ([]Request, error) {
	p := []Request{}
	if err := h.c.Call(ctx, "pending", nil, &p); err != nil {
		return nil, err
	}
	if p == nil {
		p = []Request{}
	}
	return p, nil
}

func (h *Client) Decide(ctx context.Context, id, outcome, reason string) error {
	return h.c.Call(ctx, "decide", map[string]string{"id": id, "outcome": outcome, "reason": reason}, nil)
}

func (h *Client) DenyAll(ctx context.Context, reason string) error {
	return h.c.Call(ctx, "denyAll", map[string]string{"reason": reason}, nil)
}

func (h *Client) CreateVault(ctx context.Context, pw string) error {
	return h.c.Call(ctx, "vault.create", map[string]string{"password": pw}, nil)
}

func (h *Client) SetAutoAllow(ctx context.Context, server, mode string) error {
	return h.c.Call(ctx, "servers.setAutoAllow", map[string]string{"server": server, "mode": mode}, nil)
}
```

```go
package hubapi

import "encoding/json"

type PendingEvent struct {
	Request Request `json:"request"`
}

type DecidedEvent struct {
	Request  Request  `json:"request"`
	Decision Decision `json:"decision"`
}

type LockedEvent struct {
	Reason string `json:"reason"`
}

type AutoOffEvent struct {
	Server string `json:"server"`
	Reason string `json:"reason"`
}

type AutoRanEvent struct{ AutoRan }

// Decode turns a hub notification the approval core uses into its typed
// event. Anything else (term.*, files.*, tunnels.*, audit.appended) and
// malformed params report false.
func Decode(method string, params json.RawMessage) (any, bool) {
	var ev any
	switch method {
	case "pending":
		ev = &PendingEvent{}
	case "decided":
		ev = &DecidedEvent{}
	case "locked":
		ev = &LockedEvent{}
	case "autoAllow.off":
		ev = &AutoOffEvent{}
	case "autoAllow.ran":
		ev = &AutoRanEvent{}
	default:
		return nil, false
	}
	if err := json.Unmarshal(params, ev); err != nil {
		return nil, false
	}
	switch e := ev.(type) {
	case *PendingEvent:
		return *e, true
	case *DecidedEvent:
		return *e, true
	case *LockedEvent:
		return *e, true
	case *AutoOffEvent:
```

```go
func DisplayText(s string) string {
```

```go
package model

import (
	"fmt"
	"strings"
	"time"

	"github.com/lang315/sshgate/app/hubapi"
)

// AllowDelay keeps Allow and Send to tab disabled after a request appears
// or the list changes, so nothing that moves under the pointer is pressed
// by a click meant for something else.
const AllowDelay = 500 * time.Millisecond

type PendingItem struct {
	Request hubapi.Request
	ShownAt time.Time
}

func AddPending(items []PendingItem, r hubapi.Request, now time.Time) []PendingItem {
	for _, it := range items {
		if it.Request.ID == r.ID {
			return items
		}
	}
	return append(append([]PendingItem(nil), items...), PendingItem{Request: r, ShownAt: now})
}

func RemoveDecided(items []PendingItem, id string) []PendingItem {
	out := make([]PendingItem, 0, len(items))
	for _, it := range items {
		if it.Request.ID != id {
			out = append(out, it)
		}
	}
	return out
}

func DelayElapsed(opened, changed, now time.Time) bool {
	from := opened
	if changed.After(from) {
		from = changed
	}
	return now.Sub(from) >= AllowDelay
}

func AllowEnabled(it PendingItem, now, changedAt time.Time) bool {
	return DelayElapsed(it.ShownAt, changedAt, now)
}

func ClickAllowed(it PendingItem, now, changedAt time.Time, busy bool) bool {
	return !busy && AllowEnabled(it, now, changedAt)
}

// ListChanges records when the request list last changed in a way that
// can move a button: its ids, its height, its scroll, or its mounting.
type ListChanges struct {
	At       time.Time
	key      string
	height   float32
	measured bool
}

// NewListChanges counts the column mounting as a change.
func NewListChanges(key string, at time.Time) *ListChanges {
	return &ListChanges{At: at, key: key}
}

func (l *ListChanges) SetKey(key string, now time.Time) {
	if key != l.key {
		l.key, l.At = key, now
	}
}

// SetHeight reports a height change; the first measurement is not one.
func (l *ListChanges) SetHeight(h float32, now time.Time) bool {
	if !l.measured {
		l.measured, l.height = true, h
		return false
	}
	if h == l.height {
		return false
	}
	l.height, l.At = h, now
	return true
}

func (l *ListChanges) Touch(now time.Time) { l.At = now }

// MergeSeed folds the pending snapshot into the live list: a request
// decided while the snapshot was in flight stays gone, one that arrived
// since stays shown, and known requests keep their shownAt.
func MergeSeed(current []PendingItem, snapshot []hubapi.Request, decidedSince, pendingSince map[string]bool, now time.Time) []PendingItem {
	known := map[string]PendingItem{}
	for _, it := range current {
		known[it.Request.ID] = it
	}
	inSnap := map[string]bool{}
	var out []PendingItem
	for _, r := range snapshot {
		inSnap[r.ID] = true
		if decidedSince[r.ID] {
			continue
		}
		shown := now
		if it, ok := known[r.ID]; ok {
			shown = it.ShownAt
		}
		out = append(out, PendingItem{Request: r, ShownAt: shown})
	}
	for _, it := range current {
		id := it.Request.ID
		if !inSnap[id] && !decidedSince[id] && pendingSince[id] {
			out = append(out, it)
		}
	}
	return out
}

type Segment struct {
	Text     string
	NonASCII bool
}

func isNonASCII(r rune) bool { return r > 0x7e || r < 0x20 }

// HighlightNonASCII splits s into runs of ASCII and non-ASCII characters
// (controls included) so homoglyphs and hidden characters stand out;
// characters in plain are left unmarked.
func HighlightNonASCII(s, plain string) []Segment {
	var out []Segment
	for _, r := range s {
		na := isNonASCII(r) && !strings.ContainsRune(plain, r)
		if n := len(out); n > 0 && out[n-1].NonASCII == na {
			out[n-1].Text += string(r)
			continue
		}
		out = append(out, Segment{string(r), na})
	}
	return out
}

func NonASCIISummary(s, plain string) string {
	n := 0
	var distinct []rune
	seen := map[rune]bool{}
	for _, r := range s {
		if !isNonASCII(r) || strings.ContainsRune(plain, r) {
			continue
		}
		n++
		if !seen[r] {
			seen[r] = true
			distinct = append(distinct, r)
		}
	}
	if n == 0 {
		return ""
	}
	var shown []string
	for i, r := range distinct {
		if i == 5 {
			shown = append(shown, fmt.Sprintf("+%d more", len(distinct)-5))
			break
		}
		shown = append(shown, fmt.Sprintf("U+%04X", r))
	}
	return fmt.Sprintf("%d non-ASCII character%s highlighted (%s)", n, plural(n), strings.Join(shown, ", "))
}

// StdinView shows CR as ␍ (itself highlighted); newlines and tabs stay plain.
func StdinView(s string) []Segment {
	return HighlightNonASCII(strings.ReplaceAll(s, "\r", "␍"), "\n\t")
}

func StdinMeta(s string) string {
	bytes := len(s)
	lines := 0
	if s != "" {
		lines = strings.Count(s, "\n") + 1
		if strings.HasSuffix(s, "\n") {
			lines--
		}
	}
	return fmt.Sprintf("%d byte%s, %d line%s", bytes, plural(bytes), lines, plural(lines))
}

func plural(n int) string {
	if n == 1 {
		return ""
	}
	return "s"
}
```

```go
func left(a *hubapi.AutoAllow, now time.Time) time.Duration {
	if a == nil || a.Until == "" {
		return 0
	}
	u, err := time.Parse(time.RFC3339Nano, a.Until)
	if err != nil {
		return 0
	}

func ChipLabel(a *hubapi.AutoAllow, now time.Time) string {
	if a == nil {
		return ""
	}
	if a.Forever {
		if a.Paused {
			return "Auto paused"
		}
		return "Auto ∞"
	}
	ms := left(a, now)
	if ms <= 0 {
		return ""
	}
	min := int(math.Ceil(float64(ms) / float64(time.Minute)))
	if min < 60 {
		return fmt.Sprintf("Auto %dm", min)
	}
	h, m := min/60, min%60
	if m != 0 {
		return fmt.Sprintf("Auto %dh %dm", h, m)
	}
	return fmt.Sprintf("Auto %dh", h)
}

func IsActive(a *hubapi.AutoAllow, now time.Time) bool {
	if a == nil {
		return false
	}
	if a.Forever {
		return !a.Paused
	}
	return left(a, now) > 0
}

func AutoHostNames(servers []hubapi.Server, now time.Time) []string {
	var out []string
	for _, s := range servers {
		if IsActive(s.AutoAllow, now) || (s.AutoAllow != nil && s.AutoAllow.Paused) {
			out = append(out, s.Name)
		}
	}
	return out
}

func PausedHosts(servers []hubapi.Server) []string {
	var out []string
	for _, s := range servers {
		if s.AutoAllow != nil && s.AutoAllow.Paused {
			out = append(out, s.Name)
		}
	}
	return out
}

// DropOnLock is the locked view: timed grants vanish, forever ones pause.
func DropOnLock(servers []hubapi.Server) []hubapi.Server {
	out := append([]hubapi.Server(nil), servers...)
	for i := range out {
		if out[i].AutoAllow != nil && out[i].AutoAllow.Forever {
			out[i].AutoAllow = &hubapi.AutoAllow{Forever: true, Paused: true}
		} else {
			out[i].AutoAllow = nil
		}
	}
	return out
}

func ApplyOff(servers []hubapi.Server, name string) []hubapi.Server {
	out := append([]hubapi.Server(nil), servers...)
	for i := range out {
		if out[i].Name == name {
			out[i].AutoAllow = nil
		}
	}
	return out
}

// LockHostsFrom drops hosts an autoAllow.off removed while the status call
// that listed them was in flight.
func LockHostsFrom(auto []string, dropped map[string]bool) []string {
	out := []string{}
	for _, h := range auto {
		if !dropped[h] {
			out = append(out, h)
		}
	}
	return out
}

func DropLockHost(hosts []string, server string) []string {
	out := []string{}
	for _, h := range hosts {
		if h != server {
			out = append(out, h)
		}
	}
	return out
}
```

```go
		}
	}
	return out
}
```

```go
package hubtest

import (
	"bufio"
	"encoding/json"
	"errors"
	"net"
	"path/filepath"
)

// MCPSocket is the hub's MCP door, where the bridge sends AI requests.
func MCPSocket(runtimeDir string) string { return filepath.Join(runtimeDir, "sshgate", "hub.sock") }

type ExecResult struct {
	ExitCode int
	Stdout   string
	Stderr   string
	Err      error
}

// Exec runs one MCP-door exec, as the bridge does for an AI's command, on
// its own connection; the result arrives once the hub decides and runs it.
func Exec(sock string, params map[string]any) <-chan ExecResult {
	out := make(chan ExecResult, 1)
	go func() {
		c, err := net.Dial("unix", sock)
		if err != nil {
			out <- ExecResult{Err: err}
			return
		}
		defer c.Close()
		b, _ := json.Marshal(map[string]any{"jsonrpc": "2.0", "id": 1, "method": "exec", "params": params})
		if _, err := c.Write(append(b, '\n')); err != nil {
			out <- ExecResult{Err: err}
			return
		}
		line, err := bufio.NewReader(c).ReadBytes('\n')
		if err != nil {
			out <- ExecResult{Err: err}
			return
		}
		var m struct {
			Result *struct {
				ExitCode int    `json:"exitCode"`
				Stdout   string `json:"stdout"`
				Stderr   string `json:"stderr"`
			} `json:"result"`
			Error *struct {
				Message string `json:"message"`
			} `json:"error"`
		}
		if err := json.Unmarshal(line, &m); err != nil {
			out <- ExecResult{Err: err}
			return
		}
		if m.Error != nil {
			out <- ExecResult{Err: errors.New(m.Error.Message)}
			return
		}
		out <- ExecResult{ExitCode: m.Result.ExitCode, Stdout: m.Result.Stdout, Stderr: m.Result.Stderr}
	}()
	return out
}
```

- **Hub state** [§2]. A state other than running resets `status`, `unlockErr`, `lockReason`, `lockHosts`, `items`, `seedErr`, `feed`, `decidedSince`, `pendingSince`, `seen` and the tray counter (`Shell.SetPending(0)`). Running calls `refresh()`. The app starts as `starting`.
- **`refresh()`** [§6]:

  2. Make the `status` call in a goroutine.
  3. When the reply arrives, under `Update`: set `status`, and set `lockHosts = LockHostsFrom(s.AutoHosts, dropped)`. On an error, set `status = nil` and `lockHosts = []`.
  4. Then run the screen-transition logic.
- **Screen transition**, when `ScreenFor` changes:
  - Entering `ready`: call `servers` once, and seed once (`seedGen++`). The seed resets `decidedSince` and `pendingSince`, calls `pending`, and on a reply that is still current sets `items = MergeSeed(...)` and `seedErr = ""`. If the reply has items, it adds their ids to `seen` and sets `aiOpen = true`. On an error that is still current, it sets `seedErr`.
  - Entering `create-vault`: call `servers` once.
  - Leaving `ready` or `create-vault`: clear `servers`.
  - Entering `locked`: nothing else.
- **Notes**:
  - `locked`: `lockReason = LockKind(reason, lockReason)`, `servers = DropOnLock(servers)`, then `refresh()`.
  - `autoAllow.off`: add to `dropped`, `lockHosts = DropLockHost`, and if the reason is not `locked`, `servers = ApplyOff`.
  - `autoAllow.ran`: `feed = PushFeed`.
  - `pending`:
    - add the request to `pendingSince` and `items = AddPending`;
    - if its id is not in `seen`, add it and set `aiOpen = true`;
    - add it to the counter and call `Shell.SetPending`, then `Shell.Notify(id, NotificationText)`;
    - finally `refresh()`.
  - `decided`: add to `decidedSince`, `items = RemoveDecided`, remove from the counter and call `Shell.SetPending`.
  - Anything else is ignored.
- **Actions.** Each runs on the main thread, which only starts a goroutine; the result comes back under `Update`.
  - `unlock(pw)`:
    - Clear `pw` in the field.
    - Call `Unlock`. On an error, `unlockErr` is the message. On success, clear `unlockErr` and `lockReason`.
    - Then `refresh()`.
    - Ignore the call while `busy`.
  - `lock()`: `Lock(false)`. On success clear `unlockErr`. Ignore an error, and do not `refresh()`.
  - `stopAndLock()`: `Lock(true)`. On an error, `unlockErr = "Could not stop auto-allow: " + msg`. Then `refresh()` in every case.
  - `createVault(pw)`: `CreateVault`. On an error, `createErr` is the message. Then `refresh()`.
  - `decide(id, outcome, reason)`: per-item `busy`, and per-item `err` holding the error message.
  - `denyAll()`: `DenyAll("denied all by user")`. On an error, `denyAllErr` is the message.
  - `stopAll()`: `SetAutoAllow(n, "off")` for each name in `AutoHostNames(servers, now)`. Collect the failures, and on any failure set `alert = fmt.Sprintf("Could not stop auto-allow on %s: %s", strings.Join(failed, ", "), lastMsg)`. Then reload `servers` and `refresh()`.
  - `openHost(name)`: `OpenTab` in a goroutine. On success, swap the terminal in and go to the terminal page. If a previous terminal exists, close it with `go old.Close()`. On an error, set `alert`.

```go
// HubState follows the supervisor; a hub that is not running takes every
// client-side list with it (a restarted hub starts locked with no grants).
func (a *App) HubState(st hubproc.State) {
	a.init()
	a.hubState = model.HubStateFrom(st.Kind, st.Attempt, st.In, st.Message)
	if st.Kind == "restarting" {
		a.hubSince = a.Now()
	}
	if st.Kind != "running" {
		a.status, a.unlockErr, a.lockReason, a.seedErr = nil, "", "", ""
		a.lockHosts, a.items, a.feed = []string{}, nil, nil
		a.decidedSince, a.pendingSince, a.seen = map[string]bool{}, map[string]bool{}, map[string]bool{}
		a.counter.Reset()
		a.shell().SetPending(0)
		a.setScreen()
		return
	}
	a.refresh()
}

// refresh is the one call allowed without a user action.
func (a *App) refresh() {
	a.dropped = map[string]bool{}
	go func() {
		s, err := a.hub().Status(context.Background())
		a.Update(func() {
			if err != nil {
				a.status, a.lockHosts = nil, []string{}
			} else {
				a.status = &s
				a.lockHosts = model.LockHostsFrom(s.AutoHosts, a.dropped)
			}
			a.setScreen()
		})
	}()
}

func (a *App) setScreen() {
	next := model.ScreenFor(a.hubState, a.status)
	prev := a.screen
	a.screen = next
	if next == prev {
		return
	}
	switch next {
	case model.ScreenReady:
		a.reloadServers()
		a.seed()
	case model.ScreenCreateVault:
		a.reloadServers()
	default:
		a.servers = nil
	}
}

func (a *App) reloadServers() {
	go func() {
		s, err := a.hub().Servers(context.Background())
		a.Update(func() {
			if err != nil {
				s = nil
			}
			a.servers = s
		})
	}()
}

func (a *App) seed() {
	a.seedGen++
	gen := a.seedGen
	a.decidedSince, a.pendingSince = map[string]bool{}, map[string]bool{}
	go func() {
		p, err := a.hub().Pending(context.Background())
		a.Update(func() {
			if gen != a.seedGen {
				return
			}
			if err != nil {
				a.seedErr = err.Error()
				return
			}
			a.items = model.MergeSeed(a.items, p, a.decidedSince, a.pendingSince, a.Now())
			a.seedErr = ""
			for _, r := range p {
				a.seen[r.ID] = true
			}
			if len(p) > 0 {
				a.aiOpen = true
			}
		})
	}()
}

// Note handles a hub notification; nothing here calls the hub but status.
func (a *App) Note(method string, params json.RawMessage) {
	a.init()
	ev, ok := hubapi.Decode(method, params)
	if !ok {
		return
	}
	switch e := ev.(type) {
	case hubapi.LockedEvent:
		a.lockReason = model.LockKind(e.Reason, a.lockReason)
		a.servers = model.DropOnLock(a.servers)
		a.refresh()
	case hubapi.AutoOffEvent:
		a.dropped[e.Server] = true
		a.lockHosts = model.DropLockHost(a.lockHosts, e.Server)
		if e.Reason != "locked" {
			a.servers = model.ApplyOff(a.servers, e.Server)
		}
	case hubapi.AutoRanEvent:
		a.feed = model.PushFeed(a.feed, e.AutoRan)
	case hubapi.PendingEvent:
		id := e.Request.ID
		a.pendingSince[id] = true
		a.items = model.AddPending(a.items, e.Request, a.Now())
		if !a.seen[id] {
			a.seen[id] = true
			a.aiOpen = true
		}
		a.counter.Add(id)
		a.shell().SetPending(a.counter.Count())
		title, body := model.NotificationText(e.Request)
		a.shell().Notify(id, title, body)
		a.refresh() // a refused vault reload shows before the decision
	case hubapi.DecidedEvent:
		id := e.Request.ID
		a.decidedSince[id] = true
		a.items = model.RemoveDecided(a.items, id)
		a.counter.Remove(id)
		a.shell().SetPending(a.counter.Count())
	}
}

func (a *App) unlock(pw string) {

		return

		_, err := a.hub().Unlock(context.Background(), pw)

			a.busy = false

				a.unlockErr = err.Error()
			} else {
				a.unlockErr, a.lockReason = "", ""
			}
			a.refresh()
		})
	}()
}

			}
		})
	}()
}

func (a *App) decide(id, outcome, reason string) {
	if a.itemBusy[id] {
		return
	}
	a.itemBusy[id], a.itemErr[id] = true, ""
	go func() {
		err := a.hub().Decide(context.Background(), id, outcome, reason)
		a.Update(func() {
			a.itemBusy[id] = false
			if err != nil {
				a.itemErr[id] = err.Error()
			}
		})
	}()
}

func (a *App) denyAll() {
	go func() {
		err := a.hub().DenyAll(context.Background(), "denied all by user")
		a.Update(func() {
			a.denyAllErr = ""
			if err != nil {
				a.denyAllErr = err.Error()
			}
		})
	}()
}

func (a *App) stopAll() {
	names := model.AutoHostNames(a.servers, a.Now())
	go func() {
		var failed []string
		var last string
		for _, n := range names {
			if err := a.hub().SetAutoAllow(context.Background(), n, "off"); err != nil {
				failed, last = append(failed, n), err.Error()
			}
		}
		a.Update(func() {
			a.alert = ""
			if len(failed) > 0 {
				a.alert = fmt.Sprintf("Could not stop auto-allow on %s: %s", strings.Join(failed, ", "), last)
			}
			a.reloadServers()
			a.refresh()
		})
	}()
}

// openHost dials off the main thread; a terminal it replaces is closed
// there too (term.close may wait up to 5 s on a hung hub).
func (a *App) openHost(name string) {
	if a.OpenTab == nil {
		return
	}
	go func() {
		t, err := a.OpenTab(name)
		a.Update(func() {
			if err != nil {
				a.alert = err.Error()
				return
			}
			if old := a.term; old != nil {
				go old.Close()
			}
			a.term, a.termServer, a.page = t, name, "term"
		})
	}()
}
```

```go
func segments(c *ui.Context, segs []model.Segment) {

	spans := make([]ui.Span, 0, len(segs))

func (a *App) buildColumn(c *ui.Context) {
	t := c.Theme()
	now := a.Now()
	ids := make([]string, len(a.items))
	for i, it := range a.items {
		ids[i] = it.Request.ID
	}
	key := strings.Join(ids, "\n")
	col := &a.col
	if !col.mounted || col.lc == nil {
		col.lc, col.mounted, col.lastY = model.NewListChanges(key, now), true, col.scroll.Y
	}
	if col.reasons == nil {
		col.reasons = map[string]*string{}
	}
	col.lc.SetKey(key, now)
	col.lc.SetHeight(col.listH.Bounds(c).H, now)
	if col.scroll.Y != col.lastY {
		col.lc.Touch(now)
		col.lastY = col.scroll.Y
	}
	var wait time.Duration
	for _, it := range a.items {
		if !model.AllowEnabled(it, now, col.lc.At) {
			from := it.ShownAt
			if col.lc.At.After(from) {
				from = col.lc.At
			}
			if w := model.AllowDelay - now.Sub(from); w > wait {
				wait = w
			}
		}
	}
	if wait > 0 {
		c.After(wait)
	}

	ui.Column(c).Fill().Gap(8).Padding(12).Background(t.Surface).Children(func() {
		ui.Row(c).Gap(8).Children(func() {
			title := "AI requests"
			if n := len(a.items); n > 0 {
				title += fmt.Sprintf("  %d", n)
			}
			ui.Text(c, title).Bold().Grow(1)
			if ui.Button(c, "Deny all").Disabled(len(a.items) < 2).Clicked() {
				a.denyAll()
			}
			if ui.Button(c, "×").Label("Close AI requests").Clicked() {
				a.aiOpen = false
			}
		})
		ui.Text(c, "Commands wait for you unless their host is on auto-allow. Enter in a request denies; Allow takes a mouse click.").TextColor(t.TextMuted)
		ui.Scroll(c).Grow(1).TrackScroll(&col.scroll).Children(func() {
			ui.Column(c).Gap(10).Bind(&col.listH).Children(func() {
				if a.denyAllErr != "" {

func (a *App) buildItem(c *ui.Context, it model.PendingItem, now time.Time) {

			}
		})
		ui.Text(c, model.DisplayText(r.Target)).Font("monospace").TextColor(t.TextMuted)

		if s := model.NonASCIISummary(r.Command, ""); s != "" {
```
