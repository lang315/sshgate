# mygo desktop, slice 0 (spike and skeleton) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the skeleton of the native mygo desktop app (nested module, hub subprocess, UI door client, terminal adapter, fork hooks, the guarded button, the unlock screen) and measure it against the stop gate, so the project either continues to slice 1 or stops with numbers.

**Architecture:** A new Go module at `app/` spawns `sshgate hub` and speaks the existing UI door (newline JSON-RPC, protocol 12) over its stdio. Terminal tabs are mygo `plugins/terminal` views whose `Conn` is an adapter over `term.*`. The hub, the UI door and everything under `internal/` stay unchanged.

**Tech Stack:** Go 1.27.1 (app module only), mygo (`github.com/egoist/mygo`, fork `github.com/lang315/mygo`), mygo `ui` and `plugins/terminal`, libghostty-vt built from Ghostty source with Zig 0.16.0, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-14-mygo-desktop-design.md`. Read it first; this plan implements its slice 0 and the stop gate.

## Global Constraints

- The root module (`go.mod`, `go 1.26.5`) is not edited. The app is its own module, `github.com/lang315/sshgate/app`, in `app/go.mod` with `go 1.27.1`.
- `app/go.mod` replaces `github.com/egoist/mygo` with the fork `github.com/lang315/mygo` at a pushed commit, never a local path.
- No change to `internal/`, `cmd/sshgate`, `desktop/`, or the UI door protocol (`hello` returns `{"protocol": 12}`).
- Ghostty commit `befcdfd2c3a1cb24d9ec886e93c95b2b5daa7028`, Zig `0.16.0`, `-Doptimize=ReleaseSafe`. egoist's prebuilt library is never used, so a run with neither `MYGO_GHOSTTY_VT` nor a packaged library fails rather than downloads.
- A packaged app calls `os.Unsetenv("MYGO_GHOSTTY_VT")` before `terminal.Load`, and ignores every `SSHGATE_*` knob and strips them from the hub's environment.
- `term.write` carries `user: true` only within 1000 ms of a real key, paste or IME commit (Electron's `USER_INPUT_WINDOW_MS`).
- Terminal ids match `^[A-Za-z0-9_-]{1,64}$`. Rows and cols go to the hub clamped to 1–1000.
- Only `status` may be called without a user action. Slice 0 calls nothing on a timer.
- Unix socket paths are short: tests put `SSHGATE_RUNTIME_DIR` under `os.MkdirTemp("", "sg")`, never under `t.TempDir()` or the scratchpad (104-byte limit).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never put a session URL in a commit or PR.

## Review Focus

1. The hub binary is missing, or it answers `hello` with another protocol. The app shows the error and does not hang (Task 4, `TestStartFailsOnWrongProtocol`, `TestStartFailsOnMissingBinary`).
2. `term.data` arrives for a tab already closed, or before anything reads it. Nothing panics, and data for an unknown id is dropped (Task 5, `TestMuxDropsUnknownID`).
3. The window is minimized or huge: `Resize(0, 0)` or `Resize(5000, 5000)`. The hub gets 1..1000, never an error (Task 5, `TestResizeSwapsAndClamps`).
4. The door dies while the terminal writes. `Write` still returns `len(p), nil`, because mygo closes its input queue for good on an error (Task 5, `TestWriteNeverFails`).
5. A wrong master password. The error shows, the field keeps focus, the screen stays on unlock, and nothing crashes (Task 6, `TestUnlockWrongPassword`).

```bash
#!/usr/bin/env bash
# Builds libghostty-vt from Ghostty's sources at the commit mygo's terminal
# plugin binds, ReleaseSafe (bounds and overflow checks kept), with the Zig
# Ghostty asks for. Writes <outdir>/libghostty-vt.{dylib,so} and its
# SHA-256. The build is not bit-reproducible (absolute paths in the debug
# map; the linker version): the packaging job embeds the hash of the copy
# it ships, and egoist's prebuilt library is never used.
set -euo pipefail

GHOSTTY_COMMIT=befcdfd2c3a1cb24d9ec886e93c95b2b5daa7028
ZIG_VERSION=0.16.0
out=$(mkdir -p "${1:?usage: build-ghostty-vt.sh <outdir>}" && cd "$1" && pwd)
work=${GHOSTTY_WORK:-$out/.work}
mkdir -p "$work"

case "$(uname -s)-$(uname -m)" in
  Darwin-arm64)  zplat=aarch64-macos;  zsum=b23d70deaa879b5c2d486ed3316f7eaa53e84acf6fc9cc747de152450d401489; lib=libghostty-vt.dylib ;;
  Darwin-x86_64) zplat=x86_64-macos;   zsum=0387557ed1877bc6a2e1802c8391953baddba76081876301c522f52977b52ba7; lib=libghostty-vt.dylib ;;
  Linux-x86_64)  zplat=x86_64-linux;   zsum=70e49664a74374b48b51e6f3fdfbf437f6395d42509050588bd49abe52ba3d00; lib=libghostty-vt.so ;;
  Linux-aarch64) zplat=aarch64-linux;  zsum=ea4b09bfb22ec6f6c6ceac57ab63efb6b46e17ab08d21f69f3a48b38e1534f17; lib=libghostty-vt.so ;;
  *) echo "unsupported platform $(uname -s)-$(uname -m)" >&2; exit 1 ;;
esac

zig="$work/zig-$zplat-$ZIG_VERSION/zig"
if [ ! -x "$zig" ]; then
  tarball="zig-$zplat-$ZIG_VERSION.tar.xz"
  curl -fsSL -o "$work/$tarball" "https://ziglang.org/download/$ZIG_VERSION/$tarball"
  echo "$zsum  $work/$tarball" | shasum -a 256 -c -
  tar -xJf "$work/$tarball" -C "$work"
fi

src="$work/ghostty"
if [ "$(git -C "$src" rev-parse HEAD 2>/dev/null || true)" != "$GHOSTTY_COMMIT" ]; then
  rm -rf "$src" && mkdir -p "$src"
  git -C "$src" init -q
  git -C "$src" fetch -q --depth 1 https://github.com/ghostty-org/ghostty "$GHOSTTY_COMMIT"
  git -C "$src" checkout -q FETCH_HEAD
fi

prefix="$work/prefix"
rm -rf "$prefix"
(cd "$src" && ZIG_GLOBAL_CACHE_DIR="$work/zig-cache" "$zig" build -Demit-lib-vt -Doptimize=ReleaseSafe --prefix "$prefix")
cp -L "$prefix/lib/$lib" "$out/$lib"
shasum -a 256 "$out/$lib" | cut -d' ' -f1 > "$out/libghostty-vt.sha256"
echo "MYGO_GHOSTTY_VT=$out/$lib"
```

```go
// Package door is a client for sshgate hub's UI door: newline-delimited
// JSON-RPC 2.0 over the hub's stdio (protocol 12).
package door

import (
	"bufio"
	"context"
	"encoding/json"
	"errors"
	"io"
	"sync"
)

// Error is a refusal from the hub: it answered, and said no.
type Error struct {
	Code    int    `json:"code"`
	Message string `json:"message"`
}

func (e *Error) Error() string { return e.Message }

// ErrClosed is returned for calls the hub can no longer answer.
var ErrClosed = errors.New("hub connection closed")

type message struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      *int64          `json:"id,omitempty"`
	Method  string          `json:"method,omitempty"`
	Params  json.RawMessage `json:"params,omitempty"`
	Result  json.RawMessage `json:"result,omitempty"`
	Error   *Error          `json:"error,omitempty"`
}

type reply struct {
	result json.RawMessage
	err    error
}

type Client struct {
	wmu sync.Mutex
	w   io.Writer

	mu      sync.Mutex
	next    int64
	pending map[int64]chan reply
	closed  bool

	onNote func(string, json.RawMessage)
	done   chan struct{}
}

// New starts reading r. onNote, when set, runs on the read goroutine for
// each notification, in the order the hub sent them, and must not block.
func New(r io.Reader, w io.Writer, onNote func(method string, params json.RawMessage)) *Client {
	c := &Client{w: w, pending: map[int64]chan reply{}, onNote: onNote, done: make(chan struct{})}
	go c.read(r)
	return c
}

func (c *Client) Done() <-chan struct{} { return c.done }

func (c *Client) read(r io.Reader) {
	defer c.closeAll()
	sc := bufio.NewScanner(r)
	sc.Buffer(make([]byte, 64*1024), 64*1024*1024)
	for sc.Scan() {
		var m message
		if json.Unmarshal(sc.Bytes(), &m) != nil {
			continue
		}
		if m.ID == nil {
			if m.Method != "" && c.onNote != nil {
				c.onNote(m.Method, m.Params)
			}
			continue
		}
		c.mu.Lock()
		ch := c.pending[*m.ID]
		delete(c.pending, *m.ID)
		c.mu.Unlock()
		if ch == nil {
			continue
		}
		if m.Error != nil {
			ch <- reply{err: m.Error}
		} else {
			ch <- reply{result: m.Result}
		}
	}
}

func (c *Client) closeAll() {
	c.mu.Lock()
	c.closed = true
	for id, ch := range c.pending {
		ch <- reply{err: ErrClosed}
		delete(c.pending, id)
	}
	c.mu.Unlock()
	close(c.done)
}

func (c *Client) write(m message) error {
	b, err := json.Marshal(m)
	if err != nil {
		return err
	}
	c.wmu.Lock()
	defer c.wmu.Unlock()
	if _, err := c.w.Write(append(b, '\n')); err != nil {
		return ErrClosed
	}
	return nil
}

func params(v any) (json.RawMessage, error) {
	if v == nil {
		return nil, nil
	}
	return json.Marshal(v)
}

// Call sends a request and waits for its answer, ctx, or the hub's end.
func (c *Client) Call(ctx context.Context, method string, p, result any) error {
	raw, err := params(p)
	if err != nil {
		return err
	}
	ch := make(chan reply, 1)
	c.mu.Lock()
	if c.closed {
		c.mu.Unlock()
		return ErrClosed
	}
	c.next++
	id := c.next
	c.pending[id] = ch
	c.mu.Unlock()
	if err := c.write(message{JSONRPC: "2.0", ID: &id, Method: method, Params: raw}); err != nil {
		c.mu.Lock()
		delete(c.pending, id)
		c.mu.Unlock()
		return err
	}
	select {
	case r := <-ch:
		if r.err != nil {
			return r.err
		}
		if result == nil || len(r.result) == 0 {
			return nil
		}
		return json.Unmarshal(r.result, result)
	case <-ctx.Done():
		c.mu.Lock()
		delete(c.pending, id)
		c.mu.Unlock()
		return ctx.Err()
	}
}

// Notify sends a notification; the hub answers none.
func (c *Client) Notify(method string, p any) error {
	raw, err := params(p)
	if err != nil {
		return err
	}
	return c.write(message{JSONRPC: "2.0", Method: method, Params: raw})
}
```

```go
// Package hubproc runs sshgate hub as a subprocess and keeps it running.
package hubproc

import (
	"path/filepath"
	"strings"
)

// Launch is how to start the hub.
type Launch struct {
	Command string
	Args    []string
	Env     []string
}

// LaunchFor picks the hub's binary, arguments and environment, as
// desktop/src/main/hubProcess.ts's hubLaunch does. SSHGATE_* are dev and
// test knobs: a packaged app ignores them and strips them from the hub's
// environment, because whoever sets the environment of the installed app
// could otherwise swap the hub (which receives the master password),
// point it at another vault, or stretch the idle lock.
func LaunchFor(env []string, packaged bool, resources, repoRoot, goos string, exists func(string) bool) Launch {
	knobs := map[string]string{}
	var out []string
	for _, kv := range env {
		k, v, _ := strings.Cut(kv, "=")
		if strings.HasPrefix(k, "SSHGATE_") {
			if packaged {
				continue
			}
			knobs[k] = v
		}
		out = append(out, kv)
	}
	exe := "sshgate"
	if goos == "windows" {
		exe = "sshgate.exe"
	}
	local := filepath.Join(repoRoot, exe)
	if packaged {
		local = filepath.Join(resources, exe)
	}
	args := []string{"hub"}
	if v := knobs["SSHGATE_STORE"]; v != "" {
		args = append(args, "--store="+v)
	}
	if v := knobs["SSHGATE_SSH_CONFIG"]; v != "" {
		args = append(args, "--sshConfig="+v)
	}
	if v := knobs["SSHGATE_IDLE_LOCK"]; v != "" {
		args = append(args, "--idleLock="+v)
	}
	cmd := knobs["SSHGATE_BIN"]
	if cmd == "" {
		cmd = exe
		if exists(local) {
			cmd = local
		}
	}
	return Launch{Command: cmd, Args: args, Env: out}
}
```

```go
// Start spawns the hub and checks its protocol with hello. onNote gets the
// hub's notifications on the read goroutine and must not block.
func Start(ctx context.Context, l Launch, onNote func(string, json.RawMessage)) (*Proc, error) {
	cmd := exec.Command(l.Command, l.Args...)
	cmd.Env = l.Env
	stdin, err := cmd.StdinPipe()
	if err != nil {
		return nil, err
	}
	stdout, err := cmd.StdoutPipe()
	if err != nil {
		return nil, err
	}
	stderr, err := cmd.StderrPipe()
	if err != nil {
		return nil, err
	}
	if err := cmd.Start(); err != nil {
		return nil, err
	}
	p := &Proc{cmd: cmd, stdin: stdin, done: make(chan struct{})}
	go p.readStderr(stderr)
	p.client = door.New(stdout, stdin, onNote)
	go func() { cmd.Wait(); close(p.done) }()

	hctx, cancel := context.WithTimeout(ctx, 10*time.Second)
	defer cancel()
	var hello struct{ Protocol int }
	if err := p.client.Call(hctx, "hello", map[string]any{}, &hello); err != nil {
		p.Stop()
		return nil, fmt.Errorf("hub hello: %w", err)
	}
	if hello.Protocol != Protocol {
		p.Stop()
		return nil, fmt.Errorf("hub speaks protocol %d, this app speaks %d", hello.Protocol, Protocol)
	}
	return p, nil
}

func (p *Proc) readStderr(r io.Reader) {
	sc := bufio.NewScanner(r)
	for sc.Scan() {
		p.mu.Lock()
		p.tail = append(p.tail, sc.Text())
		if len(p.tail) > stderrTail {
			p.tail = p.tail[len(p.tail)-stderrTail:]
		}
		p.mu.Unlock()
	}
}

func (p *Proc) Client() *door.Client    { return p.client }
func (p *Proc) Done() <-chan struct{}   { return p.done }
func (p *Proc) Pid() int                { return p.cmd.Process.Pid }

// StderrTail is the hub's last stderr lines.
func (p *Proc) StderrTail() []string {
	p.mu.Lock()
	defer p.mu.Unlock()
	return append([]string(nil), p.tail...)
}

// Stop closes the hub's stdin, which ends its UI door and the hub, and
// kills it if it has not exited 5 s later.
func (p *Proc) Stop() error {
	p.stdin.Close()
	select {
	case <-p.done:
	case <-time.After(5 * time.Second):
		p.cmd.Process.Kill()
		<-p.done
	}
	return nil
}
```

```go
package hubproc

import (
	"context"
	"encoding/json"
	"fmt"
	"strings"
	"time"
)

// State is what the supervisor is doing: "running", "restarting" (In is
// the delay before attempt Attempt), or "failed" (Message says why).
type State struct {
	Kind    string
	Attempt int
	In      time.Duration
	Message string
}

// Supervisor keeps a hub running: after a crash it restarts it with
// backoff (1 s, 3 s, 10 s), and gives up at the MaxCrashes-th crash within
// Window. A restarted hub starts locked.
type Supervisor struct {
	Launch     Launch
	OnNote     func(string, json.RawMessage)
	OnProc     func(*Proc) // a new hub is running
	OnState    func(State)
	Backoff    []time.Duration // default 1 s, 3 s, 10 s
	Window     time.Duration   // default 60 s
	MaxCrashes int             // default 4
}

func (s *Supervisor) state(st State) {
	if s.OnState != nil {
		s.OnState(st)
	}
}

// Run blocks until ctx ends (it then stops the hub) or it gives up.
func (s *Supervisor) Run(ctx context.Context) {
	backoff, window, max := s.Backoff, s.Window, s.MaxCrashes
	if backoff == nil {
		backoff = []time.Duration{time.Second, 3 * time.Second, 10 * time.Second}
	}
	if window == 0 {
		window = time.Minute
	}
	if max == 0 {
		max = 4
	}
	var crashes []time.Time
	var tail []string
	for {
		p, err := Start(ctx, s.Launch, s.OnNote)
		if err == nil {
			s.state(State{Kind: "running"})
			if s.OnProc != nil {
				s.OnProc(p)
			}
			select {
			case <-ctx.Done():
				p.Stop()
				return
			case <-p.Done():
				tail = p.StderrTail()
			}
		} else if ctx.Err() != nil {
			return
		} else {
			tail = []string{err.Error()}
		}
		now := time.Now()
		kept := crashes[:0]
		for _, c := range crashes {
			if now.Sub(c) < window {
				kept = append(kept, c)
			}
		}
		crashes = append(kept, now)
		if len(crashes) >= max {
			s.state(State{Kind: "failed", Message: fmt.Sprintf("the hub crashed %d times in %d s\n%s", len(crashes), int(window.Seconds()), strings.Join(tail, "\n"))})
			return
		}
		in := backoff[min(len(crashes)-1, len(backoff)-1)]
		s.state(State{Kind: "restarting", Attempt: len(crashes), In: in})
		select {
		case <-ctx.Done():
			return
		case <-time.After(in):
		}
	}
}
```

```go
// Package termconn connects a mygo terminal to a hub terminal over the UI
// door's term.* methods.
package termconn

import (
	"encoding/json"
	"strings"
	"sync"
)

// Mux routes the hub's term.* notifications to their Conn by id.
type Mux struct {
	mu    sync.Mutex
	conns map[string]*Conn
}

func NewMux() *Mux { return &Mux{conns: map[string]*Conn{}} }

func (m *Mux) add(c *Conn)       { m.mu.Lock(); m.conns[c.id] = c; m.mu.Unlock() }
func (m *Mux) remove(id string)  { m.mu.Lock(); delete(m.conns, id); m.mu.Unlock() }

// Note handles a term.* notification and reports whether it was one.
// Data for an id no Conn has (a tab already closed) is dropped. It runs on
// the door's read goroutine and never blocks.
func (m *Mux) Note(method string, params json.RawMessage) bool {
	if !strings.HasPrefix(method, "term.") {
		return false
	}
	var p struct {
		ID     string `json:"id"`
		Data   []byte `json:"data"`
		Bytes  int    `json:"bytes"`
		Reason string `json:"reason"`
	}
	if json.Unmarshal(params, &p) != nil {
		return true
	}
	m.mu.Lock()
	c := m.conns[p.ID]
	m.mu.Unlock()
	if c == nil {
		return true
	}
	switch method {
	case "term.data":
		c.push(p.Data)
	case "term.exit":
		c.exit(p.Reason)
		m.remove(p.ID)
	case "term.dropped":
		c.dropped(p.Bytes)
	}
	return true
}
```

```go
package termconn

import (
	"context"
	"encoding/json"
	"io"
	"sync"
	"time"
)

// UserWindow is how long after a real key, paste or input-method commit a
// write still counts as the user's, for the hub's idle lock (Electron's
// USER_INPUT_WINDOW_MS).
const UserWindow = time.Second

const maxDim = 1000 // internal/hub/term.go maxTermDim

// Door is the part of the UI door client a Conn uses.
type Door interface {
	Call(ctx context.Context, method string, params, result any) error
	Notify(method string, params any) error
}

// OpenError is a term.open the hub answered with another status than
// "open", as hostKeyUnknown or hostKeyMismatch.
type OpenError struct {
	Status string
	Result json.RawMessage
}

func (e *OpenError) Error() string { return "terminal not opened: " + e.Status }

// Conn is a hub terminal as an io.ReadWriteCloser for terminal.Options.Conn.
// Read returns what the hub sent and acks it, so the hub's reader stalls at
// its high-water mark while the terminal parses: that is the backpressure.
type Conn struct {
	d   Door
	m   *Mux
	id  string
	now func() time.Time

	mu       sync.Mutex
	queue    [][]byte
	buf      []byte
	ended    bool
	closed   bool
	reason   string
	drop     int
	lastUser time.Time
	ready    chan struct{} // a token when queue or ended changed
}

// Open asks the hub for a terminal on server and registers it with m.
func Open(ctx context.Context, d Door, m *Mux, id, server string, rows, cols int) (*Conn, error) {
	c := &Conn{d: d, m: m, id: id, now: time.Now, ready: make(chan struct{}, 1)}
	m.add(c) // before term.open: data may arrive before its reply
	var res json.RawMessage
	err := d.Call(ctx, "term.open", map[string]any{"id": id, "server": server, "rows": clamp(rows), "cols": clamp(cols)}, &res)
	if err != nil {
		m.remove(id)
		return nil, err
	}
	var st struct{ Status string }
	json.Unmarshal(res, &st)
	if st.Status != "open" {
		m.remove(id)
		return nil, &OpenError{Status: st.Status, Result: res}
	}
	return c, nil
}

func clamp(n int) int { return max(1, min(n, maxDim)) }

func (c *Conn) signal() {
	select {
	case c.ready <- struct{}{}:
	default:
	}
}

func (c *Conn) push(b []byte) {
	c.mu.Lock()
	if !c.ended {
		c.queue = append(c.queue, b)
	}
	c.mu.Unlock()
	c.signal()
}

func (c *Conn) exit(reason string) {
	c.mu.Lock()
	c.ended, c.reason = true, reason
	c.mu.Unlock()
	c.signal()
}

func (c *Conn) dropped(n int) { c.mu.Lock(); c.drop += n; c.mu.Unlock() }

// Dropped is how many bytes of input the hub dropped (its queue was full).
func (c *Conn) Dropped() int { c.mu.Lock(); defer c.mu.Unlock(); return c.drop }

// ExitReason is the reason term.exit gave, empty before it.
func (c *Conn) ExitReason() string { c.mu.Lock(); defer c.mu.Unlock(); return c.reason }

func (c *Conn) Read(p []byte) (int, error) {
	for {
		c.mu.Lock()
		if len(c.buf) == 0 && len(c.queue) > 0 {
			c.buf, c.queue = c.queue[0], c.queue[1:]
		}
		if len(c.buf) > 0 {
			n := copy(p, c.buf)
			c.buf = c.buf[n:]
			c.mu.Unlock()
			c.d.Notify("term.ack", map[string]any{"id": c.id, "n": n})
			return n, nil
		}
		if c.ended {
			c.mu.Unlock()
			return 0, io.EOF
		}
		c.mu.Unlock()
		<-c.ready
	}
}

// MarkUser records a real key, paste or input-method commit: writes in
// the next UserWindow count as the user's.
func (c *Conn) MarkUser() { c.mu.Lock(); c.lastUser = c.now(); c.mu.Unlock() }

// Write sends to the hub. It never fails while the tab is open: mygo's
// terminal closes its input for good on a write error. A full hub queue
// comes back as term.dropped instead.
func (c *Conn) Write(p []byte) (int, error) {
	c.mu.Lock()
	closed := c.closed
	user := !c.lastUser.IsZero() && c.now().Sub(c.lastUser) < UserWindow
	c.mu.Unlock()
	if closed {
		return 0, io.ErrClosedPipe
	}
	// An error means the hub is gone; the supervisor reports that.
	_ = c.d.Notify("term.write", map[string]any{"id": c.id, "data": p, "user": user})
	return len(p), nil
}

// Resize is mygo's (cols, rows); the hub takes rows and cols, 1..1000.
func (c *Conn) Resize(cols, rows int) error {
	c.d.Notify("term.resize", map[string]any{"id": c.id, "rows": clamp(rows), "cols": clamp(cols)})
	return nil
}

// Close ends the hub terminal once.
func (c *Conn) Close() error {
	c.mu.Lock()
	if c.closed {
		c.mu.Unlock()
		return nil
	}
	c.closed, c.ended = true, true
	c.mu.Unlock()
	c.m.remove(c.id)
	c.signal()
	c.d.Notify("term.close", map[string]any{"id": c.id})
	return nil
}
```

```go
// Package view is the app's state and its native views.
package view

import (
	"time"

	"github.com/egoist/mygo/ui"
)

// AllowDelay is how long a decisive button stays disabled after what it
// decides on changed, so nothing that moves under the pointer is pressed
// by a click meant for something else.
const AllowDelay = 500 * time.Millisecond

// Guard tracks when what a decision shows last changed. Its key is
// everything that can move a decisive button: the ids shown, the list's
// height, its scroll offset, and whether it just appeared.
type Guard struct {
	key   string
	since time.Time
}

// Note records the current key; a different key restarts the delay.
func (g *Guard) Note(key string, now time.Time) {
	if key != g.key || g.since.IsZero() {
		g.key, g.since = key, now
	}
}

func (g *Guard) Ready(now time.Time) bool { return now.Sub(g.since) >= AllowDelay }

func (g *Guard) Remaining(now time.Time) time.Duration { return max(0, AllowDelay-now.Sub(g.since)) }

// MouseButton is a button only the pointer presses: a ui.Button takes the
// focus and Enter or Space press it, so a decisive button is a row that
// never takes the focus. It reports a click only while enabled; disabled
// is set before the click is read.
func MouseButton(c *ui.Context, label string, enabled bool) bool {
	t := c.Theme()
	b := ui.Row(c).Role(ui.RoleButton).Label(label).Padding(6, 12).Radius(6).Border(1, t.Border).Disabled(!enabled)
	b.Children(func() { ui.Text(c, label) })
	return enabled && b.Clicked()
}
```

```go
// flush runs queued updates (unlock runs off the UI thread) until none
// has come for 100 ms, or 2 s have passed.
func (tt *tester) flush() {
	deadline := time.Now().Add(2 * time.Second)
	for idle := 0; idle < 10 && time.Now().Before(deadline); {
		tt.mu.Lock()
		fns := tt.pending
		tt.pending = nil
		tt.mu.Unlock()
		for _, fn := range fns {
			fn()
		}
		tt.Frame()
		if len(fns) == 0 {
			idle++
		} else {
			idle = 0
		}
		time.Sleep(10 * time.Millisecond)
	}
}
```

```go
import (

// Door is the part of the UI door client the views call.
type Door interface {
	Call(ctx context.Context, method string, params, result any) error
}

// App is the window's state. Build runs on the main thread; Update runs a
// function there from any goroutine (Window.Update, or a test's).
type App struct {
	Door    Door
	Update  func(func())
	Now     func() time.Time
	OpenTab func(server string) (*terminal.Terminal, error)

	password string
	busy     bool
	err      string
	term     *terminal.Terminal
}

func (a *App) Build(c *ui.Context) {
	if a.term != nil {
		terminal.View(c, a.term).Fill().AutoFocus()
		return
	}
	ui.Column(c).Fill().Center().Gap(12).Children(func() {
		ui.Text(c, "sshgate is locked")
		in := ui.TextInput(c, &a.password).Password().Label("Master password").AutoFocus().Disabled(a.busy)
		if in.Submitted() || ui.PrimaryButton(c, "Unlock").Disabled(a.busy).Clicked() {
			a.unlock()
		}
		if a.err != "" {
			ui.Text(c, a.err)
		}
	})
}

// unlock runs off the main thread: Argon2id takes a while.
func (a *App) unlock() {
	pw := a.password
	a.busy, a.err = true, ""
	go func() {
		ctx := context.Background()
		err := a.Door.Call(ctx, "unlock", map[string]string{"password": pw}, nil)
		var servers []struct{ Name string }
		if err == nil {
			err = a.Door.Call(ctx, "servers", nil, &servers)
		}
		a.Update(func() {
			a.busy = false
			if err != nil {
				a.err = err.Error()
				return
			}
			a.password = ""
			if len(servers) == 0 || a.OpenTab == nil {
				a.err = "no server to open"
				return
			}
			t, err := a.OpenTab(servers[0].Name)
			if err != nil {
				a.err = err.Error()
				return
			}
			a.term = t
		})
	}()
}
```

```go
package main

import (
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"strings"
)

// ghosttySHA is the SHA-256 of the libghostty-vt the packaging job built
// and shipped beside this binary (-X main.ghosttySHA=...). The build is
// not reproducible, so it binds the app to that exact copy.
var ghosttySHA string

// checkLibrary refuses a terminal library that is not the shipped one:
// outside resources, or with another SHA-256 than want.
func checkLibrary(path, resources, want string) error {
	if want == "" {
		return errors.New("no libghostty-vt hash was embedded at build time")
	}
	abs, err := filepath.Abs(path)
	if err != nil {
		return err
	}
	res, err := filepath.Abs(resources)
	if err != nil {
		return err
	}
	if rel, err := filepath.Rel(res, abs); err != nil || rel == ".." || strings.HasPrefix(rel, ".."+string(filepath.Separator)) || filepath.IsAbs(rel) {
		return fmt.Errorf("libghostty-vt %s is not inside %s", abs, res)
	}
	f, err := os.Open(abs)
	if err != nil {
		return err
	}
	defer f.Close()
	h := sha256.New()
	if _, err := io.Copy(h, f); err != nil {
		return err
	}
	if got := hex.EncodeToString(h.Sum(nil)); got != want {
		return fmt.Errorf("libghostty-vt %s has SHA-256 %s, want %s", abs, got, want)
	}
	return nil
}
```

```go
	})

		c := client.Load()
		if c == nil {
			return nil, errors.New("the hub is not running")

		conn, err := termconn.Open(context.Background(), c, mux, fmt.Sprintf("t%d", tabs), server, 24, 80)
		if err != nil {
			return nil, err
		}

			Conn:    conn,
			OnKey:   func(_ ui.Modifiers, _ ui.Key) bool { conn.MarkUser(); return false },

			OnInput: func(string) { conn.MarkUser() },

type doorFunc func(ctx context.Context, method string, params, result any) error

func (f doorFunc) Call(ctx context.Context, method string, params, result any) error {

// prepareLibrary makes sure the terminal loads the libghostty-vt built from
// source: in a packaged app, only the one shipped in Resources with the
// embedded hash; unpackaged, only MYGO_GHOSTTY_VT, never a download.

		return err
	}
	return terminal.Load()
```
