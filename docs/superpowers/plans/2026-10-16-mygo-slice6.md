# mygo desktop, slice 6 (Audit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The native mygo app shows the hub's audit log the way the Electron app's Audit tab does:
- a fixed **Audit** tab after **Hosts** in the tab strip;
- the records **newest first, under one heading per day** (Today, Yesterday, `Tue Sep 29 2026`). Each row shows its time, kind, host, result badges, the command or change, and the exit code and notes. A denied or errored exec is tinted, and a non-zero exit is amber;
- the **filters**: a host select, six chips (Exec, Auto, Denied, Config, Files, Tunnels; a union, none on means all), and a search read on Enter or 300 ms after the last key; there is also **Refresh**;
- **Load older**, the **footer** (`N malformed lines skipped · Audit file: <path>`), and an error line that keeps the rows shown;
- a row that **expands** on a click to show the full command, its stdin, the AI's description (`AI's description · unverified`), Reason, Client, Timeout, Duration, what was masked, and the **Raw JSON**;
- **live records** (`audit.appended`) that match the shown query and merge in by seq. While the list is scrolled away from the top they are held behind an **`N new`** pill. A lock empties the list, and the unlock reads it again;
- the e2e spec `audit` ported as a Go flow test against a real `sshgate hub` and `sshtestd`.

**Architecture:**
- **Layers.** Unchanged:
  - `hubapi`: typed door calls and notifications.
  - `model`: pure rules, with `audit.test.ts` ported as Go table tests.
  - `view`: the `App` controller and its screens.
  - `internal/hubtest`.
- **State.** One `auditState` on `App` (`App.audit`), always kept, as Electron's `AuditView` is always mounted:
  - the list (`model.AuditList`), the filters, and the query the list was read with;
  - a read generation, so replies to superseded reads are dropped;
  - the rows expanded, and the list's `ui.ListState`.
  
  The tab is `TabSet.Active == model.AuditTab`, which slice 1 reserved (`TabSet.ShowAudit`).
- **List.** `ui.List` with `ListState.Header`:
  - Rows are virtualized and of variable height, and the day headings stay pinned while their rows scroll.
  - Each record is a `ui.CollapsibleBase`: its trigger is the row and its panel is the detail.
  - `model.AuditLines` flattens the entries into headings and rows.

## Decisions taken in this plan (controller rulings, on the spec)

1. **The spec is unchanged.** Slice 6's row ("Table, filters, Load older, 'N new' pill") and its listed `audit` spec are met as written. The one difference: the risk line named "a virtualized `ui.List` (about 150 lines)". It is a `ui.List` with `Header` and `CollapsibleBase` rows, and the view is about 340 lines with the toolbar and detail. Cost: none.
2. **A `ui.List`, not `ui.Table`.**
   - Why not a table: a table's rows are one fixed height and hold no expandable detail.
   - Why a list:
     - it is virtualized, with variable row heights;
     - `ListState.Header` gives the day headings, pinned as Electron's sticky `tr.auditday`;
     - each record is a `CollapsibleBase`, whose trigger is the row and whose panel is the detail, as Electron's `tr.auditrow` and `tr.auditdetail`.
   - The column headings are one row above the list, at fixed widths (Command or change takes the rest); the list does not scroll sideways.
   - `ListState.Key` is deliberately unset. With a key, a record prepended at the top would anchor the list to the old first row and hide the new one above the viewport. Unkeyed, the place is an index, and a record prepended at the top shows there (probed).
   - Expanded rows are kept by seq in `auditState.open`, so a row stays open across a new read. They are dropped on a lock, as Electron's `expanded` is.
   - `AuditLines` runs in every frame: at most a few hundred records per page, and Electron recomputes `rowView` on every render too.
   - Cost: the rows are not sortable, and neither are Electron's.
3. **The chips are `ui.Toggle`s in a `ToggleGroup`, named `Filter <label>`.**
   - Their AT role is a toggle button, as Electron's `aria-pressed` buttons.
   - The visible text is Electron's (`Auto`). The name differs because the theme control already has an `Auto` button, and `Tester.Click` takes the first.
   - Cost: a screen reader says "Filter Auto".
4. **Loads and resets.**
   - `buildAudit` reads when it draws an `idle` list (`auditLoad`), which happens only when the tab shows on the ready screen.
   - `setScreen` calls `auditReset`, giving an `idle` list and dropping every read in flight, whenever the ready screen is entered or left (Electron's effect on `ready`). The unlock therefore reads again if the tab shows, and a hub restart starts over.
   - The `locked` notification calls `auditLocked`, which gives a `cleared` list, drops the reads and collapses the rows. `cleared` never loads, so nothing is read in the window before the status reply moves the screen to the unlock screen.
   - The search's 300 ms read is `typedAt` on the app clock plus `c.After` (Global Constraints, Activity rule).
   - Load older reads `Before: list.Next` with the shown query, and bumps the generation (Electron's `gen.next()`), so a newer read supersedes it.
   - Cost: none.
5. **"At the top" is `Visible()`'s first row being 0.** Electron uses `scrollTop <= 2`. Here the first row is the day heading, so a scroll of less than one heading still counts as the top. When the list is drawn at the top with records held, they are merged (Electron's `onScroll`). The `N new` pill scrolls to row 0 and merges. Cost: a record may land while the top few pixels are scrolled away, and move the rows by one row's height.
6. **The host select.** mygo's `Select` writes the chosen label outside the Build that draws it, and its `Changed()` did not report the choice in this layout (probed). So the view compares the label with the last one applied (`auditState.hostNow`). The label maps back to the server by index: names show through `DisplayText`. A host deleted while chosen stays chosen, as in Electron. Cost: none.
7. **Raw JSON is the stored line, indented** (`json.Indent`, keys in stored order), each line through `DisplayText`. Electron re-stringified the parsed object. Numbers keep their stored text (`json.Number`), which is also what the hub's search matches. Masked kinds are listed in key order: the hub writes `redacted` with sorted keys. Cost: none.
8. **Names in Go.**
   - `model.AuditTime`, not `FormatTime`, which `model/files.go` already defines.
   - The view tests' record helper is `execEntry`, because `auditRec` is the flow tests' type.
   - The record type is `model.AuditRecord` (`map[string]any`, numbers as `json.Number`), decoded once per record by `model.RowOf`.
   - Cost: none.
9. **The flow test reads the app's list, not the DOM.**
   - `TestFlowAudit` ports every assertion of `audit.spec.ts`. Rows are counted on `App.audit.list` through `model.AuditRowView`, and each is checked to show with `HasText`.
   - The 15-minute grant's row reads `15m`, or `14m` when the hub's clock rounded.
   - "Without Refresh" is checked as the read generation staying put while the live record lands.
   - Cost: none.
10. **No hub change** (ruling). Every call and text this slice needs is in protocol 12. Hub facts the app relies on, each checked by Task 1's `TestAuditAgainstRealHub` or Task 4's flow:
    - `audit.read` answers newest first, with `next` when older records match;
    - `before` reads below a seq, and the filters match as `ReadQuery.match`;
    - `path` is the audit file's;
    - the hub answers `Vault is locked; unlock it in the app` while locked and `limit must be 0-500` over 500;
    - `audit.appended` carries `{seq, record}` for each new record, in seq order.
    
    `audit.appended` is not sent while locked (`h.unlocked` in `auditAppended`). That is read in the source, and the hub's own tests own it.
11. **Safety** (ruling).
    - Tests start hubs only through `hubtest`. They write their own `audit.jsonl` beside their temp store.
    - No test starts the GUI, or touches `~/.ssh`, `~/.config/sshgate`, `~/Library/Application Support/sshgate-app`, `/Applications`, or the mygo checkout.
    - Go source holds no raw invisible or bidi rune: the Gate's byte check.
    - Cost: none.

// truthy is JavaScript's truthiness, for the fields Electron tests that way.
func truthy(v any) bool {
	switch v := v.(type) {
	case nil:
		return false
	case bool:
		return v
	case string:
		return v != ""
	case json.Number:
		f, err := v.Float64()
		return err == nil && f != 0
	}
	return true

// broker's fields.outcomeIs, for records that arrive by audit.appended.
func outcomeIs(r AuditRecord, o string) bool {
	switch o {
	case "auto":
		return r["approval"] == "auto"
	case "allowed":
		return r["outcome"] == "allowed" && r["approval"] != "auto"
	case "cancelled":
		return r["outcome"] == "approved_but_cancelled" || r["outcome"] == "cancelled_running"
	}

// leaves is what a text search sees: every string and number value,
// walked recursively, one per line, like the hub's leaves. Never a key
// name or an escape.
func leaves(v any, b *strings.Builder) {
	switch v := v.(type) {
	case string:
		b.WriteString(v)
		b.WriteByte('\n')
	case json.Number:
		b.WriteString(v.String())
		b.WriteByte('\n')
	case []any:
		for _, x := range v {
			leaves(x, b)
		}
	case AuditRecord:
		leaves(map[string]any(v), b)
	case map[string]any:
		for _, x := range v {
			leaves(x, b)
		}
	}
}

// AuditMatches reports whether r belongs in a list read with q: broker's
// ReadQuery.match, mirrored.
func AuditMatches(r AuditRecord, q hubapi.AuditQuery) bool {
	if q.Server != "" && r.str("server") != q.Server && !slices.Contains(r.list("servers"), q.Server) {
		return false
	}
	if q.Text != "" {
		var b strings.Builder
		leaves(r, &b)
		if !strings.Contains(strings.ToLower(b.String()), strings.ToLower(q.Text)) {
			return false
		}
	}
	if len(q.Kinds) == 0 && len(q.Outcomes) == 0 {
		return true
	}
	kind := r.str("kind")
	if kind == "" {
		kind = "exec"
	}
	if slices.Contains(q.Kinds, kind) {
		return true
	}
	return kind == "exec" && slices.ContainsFunc(q.Outcomes, func(o string) bool { return outcomeIs(r, o) })
}

func parseTime(s string) (time.Time, bool) {
	t, err := time.Parse(time.RFC3339Nano, s)
	return t, err == nil
}

// AuditTime is HH:MM:SS in now's zone, "" when iso is not a time. The
// day is the row group's heading (DayLabel).
func AuditTime(iso string, now time.Time) string {
	t, ok := parseTime(iso)
	if !ok {
		return ""
	}
	return t.In(now.Location()).Format("15:04:05")
}

// DayLabel is the heading of a record's day group: Today, Yesterday, or
// "Tue Sep 29 2026", in now's zone; "No date" when iso is not a time.
func DayLabel(iso string, now time.Time) string {
	t, ok := parseTime(iso)
	if !ok {
		return "No date"
	}
	day := func(t time.Time) string { return t.Format("Mon Jan 02 2006") }
	d := day(t.In(now.Location()))
	switch d {
	case day(now):
		return "Today"
	case day(now.AddDate(0, 0, -1)):
		return "Yesterday"
	}
	return d
}

func formatWait(ms float64) string {
	if ms < 1000 {
		return fmt.Sprintf("%v ms", ms)
	}
	return fmt.Sprintf("%v s", math.Round(ms/1000))
}

// grantLength is a timed grant's length (15m, 2h), from its record's time
// to its deadline.
func grantLength(r AuditRecord) string {
	if r["forever"] == true {
		return "forever"
	}
	until, ok1 := parseTime(r.str("until"))
	at, ok2 := parseTime(r.str("time"))
	if !ok1 || !ok2 {
		return ""
	}
	m := int(math.Round(until.Sub(at).Minutes()))
	if m >= 60 && m%60 == 0 {
		return fmt.Sprintf("%dh", m/60)
	}
	return fmt.Sprintf("%dm", m)
}

// AuditStdinText is an exec record's stdin as the approval card showed it:
// newlines and tabs kept, CR as ␍; every other hidden character escaped
// by DisplayText.
func AuditStdinText(s string) string {
	lines := strings.Split(strings.ReplaceAll(s, "\r", "␍"), "\n")
	for i, l := range lines {
		parts := strings.Split(l, "\t")
		for j, p := range parts {
			parts[j] = DisplayText(p)
		}
		lines[i] = strings.Join(parts, "\t")
	}
	return strings.Join(lines, "\n")
}

}

	"denied":                 {"denied", "danger"},

var camel = regexp.MustCompile(`([a-z])([A-Z])`)

// AuditRowView is r's row.
func AuditRowView(r AuditRecord, now time.Time) RowView {
	kind := r.str("kind")
	if kind != "config" && kind != "file" && kind != "tunnel" {
		kind = "exec"
	}
	v := RowView{Time: AuditTime(r.str("time"), now), Day: DayLabel(r.str("time"), now), Host: r.str("server"), Kind: kind, Side: []string{}}
	if v.Host == "" {
		v.Host = strings.Join(r.list("servers"), ", ")
	}
	switch kind {
	case "config":
		action := r.str("action")
		changed := r.list("changed")
		switch {
		case action == "autoAllowOn":
			v.Main = grantLength(r)
		case action == "softLock":
			v.Main = strings.Join(r.list("servers"), ", ")
		case len(changed) > 0:
			v.Main = strings.Join(changed, ", ")
		default:
			v.Main = cmpOr(r.str("reason"), r.str("fingerprint"), r.str("oldFingerprint"))
		}
		// The badge spaces the camelCase action (autoAllowOn reads "auto allow
		// on"); Raw JSON keeps the stored name, which is what a search matches.
		v.Badges = []Badge{{strings.ToLower(camel.ReplaceAllString(action, "$1 $2")), "plain"}}
		return v
	case "file":
		if r["action"] == "rename" {
			v.Main = r.str("from") + " → " + r.str("to")
		} else if l := r.list("remote"); len(l) > 0 {
			v.Main = l[0]
		}
		v.Badges = []Badge{{r.str("action"), "plain"}}
		if truthy(r["phase"]) {
			v.Side = []string{r.str("phase")}
		}
		return v
	case "tunnel":
		v.Badges = []Badge{{r.str("phase"), "plain"}}
		if truthy(r["to"]) {
			v.Main = r.str("listen") + " → " + r.str("to")
		} else {
			v.Main = r.str("listen") + " SOCKS5"
		}
		return v
	}
	outcome := r.str("outcome")
	auto := r["approval"] == "auto"
	if auto {
		v.Badges = append(v.Badges, Badge{"auto", "auto"})
	}
	if !auto || outcome != "allowed" {
		b, ok := execBadge[outcome]
		if !ok {
			b = Badge{outcome, "plain"}
		}
		v.Badges = append(v.Badges, b)
	}
	if r["sudo"] == true {
		v.Badges = append(v.Badges, Badge{"sudo", "danger"})
	}
	if w, ok := r.num("waitMs"); ok && w > 0 {
		v.Side = append(v.Side, "wait "+formatWait(w))
	}
	if n := MaskedCount(r); n > 0 {
		v.Side = append(v.Side, fmt.Sprintf("%d masked", n))
	}
	if e, ok := r.num("exitCode"); ok {
		code := int(e)
		v.Exit = &code
	}
	v.Alert = outcome == "denied" || outcome == "error"
	v.Main = r.str("command")
	return v
}

	}
	if n, ok := r["durationMs"].(json.Number); ok {
		out = append(out, AuditFact{"Duration", n.String() + " ms"})
	}
	return out
}

// AuditMasked is the expanded row's "Masked: password ×2, token ×1", or ""
// when nothing was masked.
func AuditMasked(r AuditRecord) string {
	if MaskedCount(r) <= 0 {
		return ""
	}
	kinds, counts := maskedKinds(r)
	parts := make([]string, len(kinds))
	for i, k := range kinds {
		parts[i] = fmt.Sprintf("%s ×%v", DisplayText(k), counts[i])
	}
	return "Masked: " + strings.Join(parts, ", ")
}

// AuditRaw is the record as stored, indented, each line through
// DisplayText.
func AuditRaw(raw json.RawMessage) string {
	var b bytes.Buffer
	if json.Indent(&b, raw, "", "  ") != nil {
		return DisplayText(string(raw))
	}
	lines := strings.Split(b.String(), "\n")
	for i, l := range lines {
		lines[i] = DisplayText(l)
	}
	return strings.Join(lines, "\n")
}

// AuditList is the records the tab holds. "cleared" follows a lock and
// never loads by itself; the view resets it to "idle" when the ready
// screen is entered, and reads from "idle" only while the tab shows.
type AuditList struct {
	Status  string     // "idle", "loading", "loaded", "error" or "cleared"
	Entries []AuditRow // newest first, one per seq
	Held    []AuditRow // live records that arrived while scrolled away: "N new"
	Next    int        // the Before of Load older; 0 when nothing is older
	Skipped int
	Path    string
	Error   string
}

// MergeEntries is a and b, one per seq, newest first.
func MergeEntries(a, b []AuditRow) []AuditRow {
	seen := map[int]bool{}
	var out []AuditRow
	for _, e := range slices.Concat(a, b) {
		if !seen[e.Seq] {
			seen[e.Seq] = true
			out = append(out, e)
		}
	}
	slices.SortStableFunc(out, func(x, y AuditRow) int { return y.Seq - x.Seq })
	return out
}

// StartLoad is a fresh list loading; it keeps the path shown.
func StartLoad(l AuditList) AuditList { return AuditList{Status: "loading", Path: l.Path} }

// ApplyPage adds a page. A page's Skipped counts only the lines that read
// scanned, so the pages of one list add up; StartLoad starts the count over.
func ApplyPage(l AuditList, p hubapi.AuditPage) AuditList {
	rows := make([]AuditRow, len(p.Records))
	for i, e := range p.Records {
		rows[i] = RowOf(e)
	}
	l.Status, l.Entries, l.Next, l.Skipped, l.Path, l.Error = "loaded", MergeEntries(l.Entries, rows), p.Next, l.Skipped+p.Skipped, p.Path, ""
	return l
}

// FailLoad keeps what is shown, with the error.
func FailLoad(l AuditList, msg string) AuditList {
	l.Status, l.Error = "error", msg
	return l
}

// AppendLive adds an audit.appended record: kept only while a list is
// loading or loaded, if it matches the query that list was read with and
// is not there yet; held while the list is scrolled away from the top, so
// rows never move under the cursor. It reports whether l changed.
func AppendLive(l AuditList, e AuditRow, q hubapi.AuditQuery, atTop bool) (AuditList, bool) {
	if l.Status != "loading" && l.Status != "loaded" {
		return l, false
	}
	if !AuditMatches(e.Rec, q) {
		return l, false
	}
	// The normal case is a seq above everything held: prepend, no sort.
	// Out of order falls back to the merge, which also dedupes.
	top := 0
	if len(l.Entries) > 0 {
		top = l.Entries[0].Seq
	}
	if len(l.Held) > 0 {
		top = max(top, l.Held[0].Seq)
	}
	fresh := e.Seq > top
	has := func(r AuditRow) bool { return r.Seq == e.Seq }
	if !fresh && (slices.ContainsFunc(l.Entries, has) || slices.ContainsFunc(l.Held, has)) {
		return l, false
	}
	add := func(list []AuditRow) []AuditRow {
		if fresh {
			return append([]AuditRow{e}, list...)
		}
		return MergeEntries(list, []AuditRow{e})
	}
	if atTop {
		l.Entries = add(l.Entries)
	} else {
		l.Held = add(l.Held)
	}
	return l, true
}

// ReleaseHeld moves the held records into the list.
func ReleaseHeld(l AuditList) AuditList {
	if len(l.Held) > 0 {
		l.Entries, l.Held = MergeEntries(l.Entries, l.Held), nil
	}
	return l
}

// ClearOnLock is the list after a lock: nothing shown, nothing loads.
func ClearOnLock() AuditList { return AuditList{Status: "cleared"} }

// AuditLine is one row of the tab's list: a day heading (Heading set) or a
// record with its view.
type AuditLine struct {
	Heading string
	Row     AuditRow
	View    RowView
}

// AuditLines is entries under one heading per day, newest first.
func AuditLines(entries []AuditRow, now time.Time) []AuditLine {
	var out []AuditLine
	for i, e := range entries {
		v := AuditRowView(e.Rec, now)
		if i == 0 || v.Day != out[len(out)-1].View.Day {
			out = append(out, AuditLine{Heading: v.Day, View: RowView{Day: v.Day}})
		}
		out = append(out, AuditLine{Row: e, View: v})
	}
	return out
}

// auditDoor answers audit.read from recs, newest first, as the hub
// filters them; limit records a page, Next set when older ones are left.
func auditDoor(recs *[]hubapi.AuditEntry, limit int) func(q hubapi.AuditQuery) hubapi.AuditPage {
	return func(q hubapi.AuditQuery) hubapi.AuditPage {
		p := hubapi.AuditPage{Records: []hubapi.AuditEntry{}, Path: "/a/audit.jsonl"}

			}
			if len(p.Records) == limit {
				p.Next = p.Records[limit-1].Seq
				break
			}
			p.Records = append(p.Records, e)
		}
		return p
	}
}

type auditState struct {

func (a *App) auditAppended(e hubapi.AuditEntry) {

	v.gen++
	v.older, v.typedAt = false, time.Time{}
	v.query = model.AuditQueryFor(v.filters)
	v.list = model.StartLoad(v.list)

	v.atTop = true
	a.auditRead(v.query, false)
}

// auditLoadOlder reads the page below the last row shown.
func (a *App) auditLoadOlder() {
	v := &a.audit
	if v.older || v.list.Status != "loaded" || v.list.Next == 0 {
		return
	}
	v.gen++
	v.older = true
	q := v.query
	q.Before = v.list.Next
	a.auditRead(q, true)
}

func (a *App) auditRead(q hubapi.AuditQuery, older bool) {
	v := &a.audit
	gen, hubGen := v.gen, a.hubGen
	go func() {
		p, err := a.hub().AuditRead(context.Background(), q)
		a.Update(func() {
			if gen != v.gen || hubGen != a.hubGen {
				return
			}
			if older {
				v.older = false
			}
			if err != nil {
				v.list = model.FailLoad(v.list, err.Error())
				return
			}
			v.list = model.ApplyPage(v.list, p)
		})
	}()
}
