# mygo desktop, slice 7 (macOS finish) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The native mygo app does what the Electron app does on macOS, and is packaged as a bundle you can install in its place:
- **Touch ID unlock.**
  - **Settings → Unlock** has a switch, `Unlock with Touch ID`. Turning it on asks the master password again. Turning it off needs none.
  - The unlock screen has an `Unlock with Touch ID` button, and asks by itself once per locked episode: at start with the window focused, or on the first focus while locked, never at the moment of locking.
  - The password goes helper → app → the hub's `unlock` and never into a view. A changed fingerprint set, or a wrong password, turns Touch ID off.
- **Background mode.** Closing the window hides it and the Dock icon. The hub and the unlocked vault keep running behind the menu bar icon. The tray's `Show`, a notification click and a re-launch bring the window back. Cmd+Q, the tray's Quit and SIGTERM still quit.
- **`sshgate.app`.** One script, `app/scripts/package-mac.sh`, builds `app/out/sshgate.app` (about 25 MB, ad-hoc signed): the app, the `sshgate` binary (hub and bridge), the Touch ID helper, the libghostty-vt built from source, the icon, and the version. CI runs it on macOS.
- The e2e specs `touchid` and `background` ported: `touchid` as Go flow tests against a real hub and a fake helper, `background` as its decision rule plus hand checks, since mygo's window and Dock cannot be driven headless.

**Architecture:**
- **Layers.** Unchanged: `hubapi`, `model`, `view`, `hubtest`. One package is added:
  - `touchid`: `Manager` runs the helper (`available`, `enroll`, `unlock`), keeps `touchid.json`, and calls the hub's `status` and `unlock`. A port of `desktop/src/main/touchid.ts`.
- **State.** `App.Touch` (a `view.Toucher`, `touchid.Manager` in main) and a few fields on `App`: the status read last, whether this locked episode asked already, whether a helper is up, whether the ready screen was ever shown, and whether the window has the focus. `main` feeds the focus in with `App.WindowFocus`.
- **Rules.** `model.TouchStatus`, `TouchChange`, `AutoTouch`, and `SaveAllowed` / `SettingsChangeKey` extended with Touch ID, as `settings.ts` and `shell.ts` do.
- **Main.** `cmd/sshgate-app` wires the manager, the close hook (`closeHook`), `OnBeforeQuit`, `OnActivate` and the window's focus events. `showWindow` shows the Dock icon again.
- **Packaging.** A shell script, not `mygo build` (Decision 1).

**Tech Stack:**
- Go 1.27.1 (`app/` module), mygo `ui` and the app lifecycle (`Window.OnClose`, `Application.OnBeforeQuit`, `OnActivate`, `Dock.Hide` / `Show`), fork commit `25387f1`.
- `sshgate-touchid` (Swift, CryptoKit, built by `desktop/scripts/build-touchid.sh`), `codesign`, `PlistBuddy`.
- `sshgate hub` (UI door protocol 12, unchanged) and `sshtestd`.

## Review Focus

1. **A close that blocks Quit.**
   - Expected: a window close hides the window on macOS, but Cmd+Q, the tray's Quit and SIGTERM still quit. `App.Quit` closes every window, so a close hook that always prevents the close would cancel all three.
   - Covered by Task 5: `TestCloseHookHidesInsteadOfClosingUnlessQuitting`, and the hand check of the three ways to quit.
2. **Touch ID asking again and again.**
   - Expected: a cancel hands the focus back to the window, which must not open the dialog again. One ask per locked episode, however many focus events.
   - Covered by Task 3: `TestTouchAsksOnTheFirstFocusOfAnEpisodeOnly`, `TestTouchNeverAsksAtTheMomentOfLockingAndAsksAgainNextEpisode`; Task 1: `TestAutoTouch`.
3. **A `touchid.json` that is not this vault's.**
   - Expected: a file for another store, a corrupt one, or a blob that is not a version 1 object reads as "not enabled"; nothing is deleted or rewritten, and an unlock says `Touch ID is not turned on`.
   - Covered by Task 2: `TestAnotherStoreACorruptFileOrABlobWithoutVersionOneIsNotEnabled`.
4. **The password reaching anything but the hub.**
   - Expected: it goes to the helper on stdin and back on stdout, then to the hub's `unlock`, byte for byte, with quotes, a backslash, a non-ASCII rune and a trailing newline kept. The helper's stdout buffer is zeroed after use.
   - Covered by Task 2: `TestUnlockPassesThePasswordToTheHubByteForByte`.
5. **A Touch ID dialog outliving what it was for.**
   - Expected: a typed password that unlocks closes it, and a hub that stops closes it, with `Touch ID was interrupted…` shown on the next lock screen. A reset deletes the file and removes the button.
   - Covered by:
     - Task 2: `TestOneHelperAtATimeAndCancelKillsIt`, `TestCancelWithAReasonRejectsWithIt`, `TestCancelBeforeTheHelperStartsStopsIt`.
     - Task 3: `TestTouchCancelsOnATypedUnlockAndOnAHubStop`, `TestTouchErrorShowsAndStatusIsReadAgain`.
     - Task 4: `TestFlowTouchIDHubStopClosesTheDialog`, `TestFlowTouchIDFingerprintsChanged`.
6. **A bundle that cannot run, or ships the wrong parts.**
   - Expected: the script refuses a library whose hash is not the one in `build/natives`, a missing helper or icon, and a `sshgate --version` that is not the manifest's version.
   - Covered by Task 6: `TestManifest`, and the script's own checks (its last lines).

## Decisions taken in this plan (controller rulings, on the spec)

1. **The bundle is built by a script, not by `mygo build`.** The spec's packaging line says "`.app` packaging with `sshgate`, `sshgate-touchid` and libghostty-vt, version stamp" and does not name the tool. `mygo build` makes a signed bundle offline, but (`mygo-package.md`, verified):
   - it always ships egoist's prebuilt `libghostty-vt.dylib`, and a library of ours placed in `resources/` fails with "would both be installed";
   - it overrides any `-ldflags`, so `-X main.ghosttySHA=<hash>` cannot be set, and the app then refuses to start (`no libghostty-vt hash was embedded at build time`).

   The script is 70 lines: it builds the app with `-tags mygo_noinspector -X github.com/egoist/mygo.production=1 -X main.ghosttySHA=…`, builds `sshgate`, copies the helper, the library (not re-signed: that would change the hash the app checks) and the icon, writes `Info.plist`, signs once, and checks the result. Cost: `Info.plist` is ours to keep right; `mygo build`'s `.dmg` is not produced.
2. **The version lives in `app/mygo.json`** (the spec: "reads it from `mygo.App.Version()` (`mygo.json`)"). The script reads `version` and `identifier` from it with `sed`; the bundle's `CFBundleShortVersionString` is what `mygo.App.Version()` returns, and the same text goes into `sshgate` with `-X internal/mcpserver.Version`. It starts at `0.1.0`, the Electron app's. `TestManifest` pins the file's keys and format. Cost: a version bump touches one line, here, and `desktop/package.json` no longer follows it.
3. **The app shares the Electron app's data folder.** The bundle's name is `sshgate`, so `mygo.App.Path(PathUserData)` is `~/Library/Application Support/sshgate`, where the Electron app's `touchid.json` already is. The two use the same format, so a Touch ID enrolled in one works in the other. The two apps also share the hub's socket and the vault, so only one can run: that is the spec's "mutually exclusive". The unpackaged app stays in `sshgate-app`. Cost: none; the plan's tests use neither folder.
4. **Touch ID is its own seam, `view.Toucher`, not part of `Shell`.** It spawns a process and keeps a file, and can be faked with a script. `Shell` stays window and tray chrome. `App.Touch` is nil in older tests and in an app without it: Settings then opens at once and shows no Unlock section.
5. **Settings opens after Touch ID's state is read.** With Touch ID present the gear click reads the status first (a helper process, no hub call besides `status`) and opens the dialog when the reply lands, as the Electron app awaits `loadTouch()`. A late reply opens nothing if a lock, a hub stop or a second click got there first.
6. **The master password field takes the focus through a `Handle`.** `AutoFocus` gives the focus as an element appears at a dialog's opening; on a field that appears later, when the switch is turned on, it did not (probed). So the field is bound to a `ui.Handle`, and `Focus()` is called when it first shows. Enter in it means Cancel, as everywhere in this dialog (Save is mouse-only).
7. **Save order.** Touch ID first, then the limit if it changed, as `saveSettings` in `settings.ts`. A Touch ID error leaves the limit unsaved and the dialog open. When Touch ID worked and the limit failed, the dialog's Touch ID state is updated, so a retry changes only the limit.
8. **The window's focus reaches the views as `App.WindowFocus(bool)`.** The `ui` package tracks the window's focus but exports no getter, so `main` feeds it from `Window.OnFocus` / `OnBlur` (and at start, from `IsFocused`). `AutoTouch` takes it as `focused`.
9. **Background mode is macOS only.** `closeHook` prevents the close and hides only when `runtime.GOOS == "darwin"` and the app is not quitting; `OnBeforeQuit` sets the flag, because `App.Quit` closes every window and runs each `OnClose`. Hub shutdown stays after `App.Run` returns, so hiding touches nothing there. If a quit were cancelled by something else the flag would stay set and later closes would close: benign. Cost: none.
10. **What the Tester cannot check.** mygo's fake backend is an internal package, so no test here can close a real window or see the Dock. The rule is unit-tested (`hidesOnClose`, `closeHook`), and the rest is in Hand checks. `background.spec.ts`'s other assertion, that the hub still serves after a close, holds by construction (a hide closes nothing) and is a hand check.
11. **CI packages on macOS only.** The step runs after the tests in the macOS job, which already builds libghostty-vt. The script needs `swiftc`, `codesign` and `PlistBuddy`. It calls `desktop/scripts/build-touchid.sh`; that script and `desktop/native/touchid/main.swift` move into `app/` when `desktop/` is deleted, which is decided separately. Cost: the CI job gets about 10 s longer.
12. **The mygo app does not replace the installed Electron app by itself.** The plan builds `app/out/sshgate.app`. Installing it, and quitting the Electron app first, is the author's act (Hand checks). Deleting `desktop/` waits for that.
13. **No hub change** (ruling). Touch ID needs only `status` and `unlock`, both in protocol 12. The hub's `wrong master password` text is what the manager matches; `internal/hub/hub.go` sends it.
14. **Safety** (ruling).
    - No test or step starts the GUI or the packaged app, or touches the folders and vault named in the Global Constraints.
    - Go source holds no raw invisible or bidi rune: the Gate's byte check.
    - Cost: none.

// TouchStatus is what the Touch ID helper says about this Mac and this
// vault. Supported is false with no helper (any system but macOS, or a
// missing binary): then nothing is shown and nothing is spawned.
type TouchStatus struct{ Supported, Available, Enabled bool }

// TouchChange is Settings' Unlock switch against the status it opened with:
// "same", "on" (Touch ID is being turned on, so the master password is
// asked again) or "off".
func TouchChange(enabled, on bool) string {
	switch {
	case on == enabled:
		return "same"
	case on:
		return "on"
	}
	return "off"
}

// AutoTouch is whether the unlock screen asks Touch ID by itself, once per
// locked episode: never when it was asked already (a cancel counts), never
// when locked is false or Touch ID is off or not usable, and only on the
// first focus of the window (trigger "focus") or at start (trigger "start")
// when the window has the focus and the ready screen was never shown. It is
// never asked at the moment of locking: the lock gives no trigger.
func AutoTouch(trigger string, locked bool, t *TouchStatus, asked, everReady, focused bool) bool {
	if !locked || t == nil || !t.Enabled || !t.Available || asked {
		return false
	}
	return trigger == "focus" || (!everReady && focused)
}

// Package touchid unlocks the vault with Touch ID: it runs sshgate-touchid,
// a Swift helper that seals the master password to a Secure Enclave key and
// opens it behind a fingerprint, keeps the sealed blob in touchid.json, and
// sends the opened password to the hub's unlock itself, so it never reaches
// the views. A port of desktop/src/main/touchid.ts; the rules are in
// docs/superpowers/specs/2026-10-12-touchid-unlock-design.md.
package touchid

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"os"
	"os/exec"
	"path/filepath"
	"strings"
	"sync"

	"github.com/lang315/sshgate/app/hubapi"

// What the person is told, character for character as the Electron app says it.
var (
	ErrReset       = errors.New("Touch ID was turned off because your fingerprints changed or your master password is different. Unlock with your password, then turn it on again in Settings.")
	ErrUnavailable = errors.New("Touch ID is not available right now. Unlock with your password.")
	ErrFailed      = errors.New("Touch ID failed.")
	ErrBusy        = errors.New("Touch ID is already asking")
	ErrOff         = errors.New("Touch ID is not turned on")
	// ErrInterrupted is the reason Cancel gets when the hub stops under a dialog.
	ErrInterrupted = errors.New("Touch ID was interrupted because the app restarted its background process. Unlock again.")
)

// wrongPassword is the hub's answer to a wrong master password.
const wrongPassword = "wrong master password"

// Hub is the part of the UI door the manager calls.
type Hub interface {
	Status(ctx context.Context) (hubapi.Status, error)
	Unlock(ctx context.Context, password string) (hubapi.UnlockReply, error)
}

// Result is a Touch ID unlock: Cancelled when the person dismissed the
// dialog (nothing to show), else the hub's reply.
type Result struct {
	Cancelled bool
	Reply     hubapi.UnlockReply
}

// HelperPath is the helper to run, "" when there is none. Like the hub's
// launch, SSHGATE_TOUCHID_HELPER is a dev and test knob that a packaged app
// ignores: whoever sets the environment could otherwise swap the helper that
// receives the master password. Otherwise it is sshgate-touchid in
// Resources when packaged, beside the module root when not, on macOS only.
func HelperPath(env []string, packaged bool, resources, repoRoot, goos string, exists func(string) bool) string {
	if !packaged {
		for _, kv := range env {
			if v, ok := strings.CutPrefix(kv, "SSHGATE_TOUCHID_HELPER="); ok && v != "" {
				return v
			}
		}
	}
	if goos != "darwin" {
		return ""
	}
	dir := repoRoot
	if packaged {
		dir = resources
	}
	if p := filepath.Join(dir, "sshgate-touchid"); exists(p) {
		return p
	}
	return ""
}

// Manager runs the helper. Helper "" means Touch ID is not supported here:
// every call answers so and nothing is spawned. File is touchid.json.
type Manager struct {
	Helper string
	File   string
	// Hub returns the hub's client now; it changes when the hub restarts.
	Hub func() Hub

	mu        sync.Mutex
	running   *exec.Cmd
	busy      bool
	gen       int   // bumped by Cancel: an unlock begun before it stops at its next step
	cancelErr error // why, when Cancel gave a reason
}

// run is one helper process. A helper that cannot start counts as 4 (not
// available), one killed by a signal as 1; Cancel is told apart by gen, not
// by the code. track makes Cancel able to kill it.
type run struct {
	code   int
	stdout []byte
	stderr string
}

func (m *Manager) run(args []string, input []byte, track bool) run {
	cmd := exec.Command(m.Helper, args...)
	var out, errb bytes.Buffer
	cmd.Stdin, cmd.Stdout, cmd.Stderr = bytes.NewReader(input), &out, &errb
	if err := cmd.Start(); err != nil {
		return run{code: 4}
	}
	if track {
		m.mu.Lock()
		m.running = cmd
		m.mu.Unlock()
	}
	err := cmd.Wait()
	if track {
		m.mu.Lock()
		if m.running == cmd {
			m.running = nil
		}
		m.mu.Unlock()
	}
	code := 0
	if err != nil {
		code = 1
		var ee *exec.ExitError
		if errors.As(err, &ee) && ee.ExitCode() > 0 {
			code = ee.ExitCode()
		}
	}
	return run{code: code, stdout: out.Bytes(), stderr: errb.String()}
}

// wipe zeroes bytes that held the password. A Go string cannot be wiped; the
// bytes can.
func wipe(b []byte) {
	for i := range b {
		b[i] = 0
	}
}

// file is touchid.json: the sealed blob for one vault.
type file struct {
	StorePath string          `json:"storePath"`
	Sealed    json.RawMessage `json:"sealed"`
}

// read is the sealed blob for this vault, or nil: no file, a corrupt one, one
// for another store, or a blob that is not a version 1 object.
func (m *Manager) read(storePath string) json.RawMessage {
	b, err := os.ReadFile(m.File)
	if err != nil {
		return nil
	}
	var f file
	var v struct {
		V int `json:"v"`
	}
	if json.Unmarshal(b, &f) != nil || f.StorePath != storePath || json.Unmarshal(f.Sealed, &v) != nil || v.V != 1 {
		return nil
	}
	return f.Sealed
}

// Status says whether Touch ID can be offered. A hub that is not running
// reads as not enabled.
func (m *Manager) Status(ctx context.Context) model.TouchStatus {
	if m.Helper == "" {
		return model.TouchStatus{}
	}
	st := model.TouchStatus{Supported: true, Available: m.run([]string{"available"}, nil, false).code == 0}
	if s, err := m.Hub().Status(ctx); err == nil {
		st.Enabled = m.read(s.StorePath) != nil
	}
	return st
}

// Enable checks the master password with the hub, seals it, and writes
// touchid.json (0600, atomically). A wrong password writes nothing.
func (m *Manager) Enable(ctx context.Context, password string) error {
	if password == "" {
		return errors.New("Type your master password")
	}
	if m.Helper == "" {
		return ErrUnavailable
	}
	hub := m.Hub()
	s, err := hub.Status(ctx)
	if err != nil {
		return err
	}
	// With no vault the hub's unlock accepts any password, so it proves nothing.
	if !s.HasVault {
		return errors.New("create a vault first")
	}
	if _, err := hub.Unlock(ctx, password); err != nil { // checks it; a wrong one leaves the hub as it was
		return err
	}
	input := []byte(password)
	r := m.run([]string{"enroll"}, input, false)
	wipe(input)
	if r.code == 4 {
		return ErrUnavailable
	}
	var sealed json.RawMessage
	if r.code != 0 || json.Unmarshal(r.stdout, &sealed) != nil || len(sealed) == 0 || sealed[0] != '{' {
		fmt.Fprintf(os.Stderr, "sshgate: touchid enroll failed: %d %s\n", r.code, r.stderr)
		return ErrFailed
	}
	b, err := json.Marshal(file{StorePath: s.StorePath, Sealed: sealed})
	if err != nil {
		return err
	}
	if err := os.MkdirAll(filepath.Dir(m.File), 0o700); err != nil {
		return err
	}
	tmp := fmt.Sprintf("%s.%d.tmp", m.File, os.Getpid())
	_ = os.Remove(tmp)
	if err := os.WriteFile(tmp, b, 0o600); err != nil {
		return err
	}
	return os.Rename(tmp, m.File)
}

// Disable deletes touchid.json; it needs no password.
func (m *Manager) Disable() error {
	if err := os.Remove(m.File); err != nil && !errors.Is(err, os.ErrNotExist) {
		return err
	}
	return nil
}

// Unlock opens the sealed password behind a fingerprint and sends it to the
// hub's unlock. The helper's exit codes: 2 the person cancelled (the file
// stays), 3 the key no longer works (the file goes), 4 Touch ID is not usable
// now, anything else failed. The hub saying wrong master password also
// deletes the file. One helper at a time.
func (m *Manager) Unlock(ctx context.Context) (Result, error) {
	m.mu.Lock()
	if m.busy {
		m.mu.Unlock()
		return Result{}, ErrBusy
	}
	if m.Helper == "" {
		m.mu.Unlock()
		return Result{}, ErrUnavailable
	}
	m.busy = true
	gen := m.gen
	m.mu.Unlock()
	defer func() { m.mu.Lock(); m.busy = false; m.mu.Unlock() }()

	hub := m.Hub()
	s, err := hub.Status(ctx)
	if err != nil {
		return Result{}, err
	}
	sealed := m.read(s.StorePath)
	if sealed == nil {
		return Result{}, ErrOff
	}
	if done, res, err := m.stopped(gen); done {
		return res, err
	}
	r := m.run([]string{"unlock"}, sealed, true)
	defer wipe(r.stdout)
	if done, res, err := m.stopped(gen); done {
		return res, err
	}
	switch r.code {
	case 0:
	case 2:
		return Result{Cancelled: true}, nil
	case 3:
		_ = m.Disable()
		return Result{}, ErrReset
	case 4:
		return Result{}, ErrUnavailable
	default:
		fmt.Fprintf(os.Stderr, "sshgate: touchid unlock failed: %d %s\n", r.code, r.stderr)
		return Result{}, ErrFailed
	}
	reply, err := hub.Unlock(ctx, string(r.stdout))
	var de *door.Error
	if errors.As(err, &de) && de.Message == wrongPassword {
		_ = m.Disable()
		return Result{}, ErrReset
	}
	if err != nil {
		return Result{}, err
	}
	return Result{Reply: reply}, nil
}

// stopped is whether a Cancel landed since gen was read, and what it means:
// its reason, or a cancel the person is shown nothing for.
func (m *Manager) stopped(gen int) (bool, Result, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	switch {
	case m.gen == gen:
		return false, Result{}, nil
	case m.cancelErr != nil:
		return true, Result{}, m.cancelErr
	}
	return true, Result{Cancelled: true}, nil
}

// Cancel closes a Touch ID dialog still up and stops an unlock that has not
// started its helper yet: a typed password won (no reason: the person sees
// nothing), or the hub stopped (reason is the error shown).
func (m *Manager) Cancel(reason error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	m.gen++
	m.cancelErr = reason
	if m.running != nil {
		_ = m.running.Process.Kill()
	}
}

// calls run in goroutines and come back through Update.
type Toucher interface {
	Status(ctx context.Context) model.TouchStatus
	Enable(ctx context.Context, password string) error
	Disable() error
	Unlock(ctx context.Context) (touchid.Result, error)
	Cancel(reason error)
}

// WindowFocus follows the window's focus (main feeds it from mygo's OnFocus
// and OnBlur): the first focus of a locked episode asks Touch ID by itself.
func (a *App) WindowFocus(focused bool) {
	a.init()
	a.focused = focused
	if focused {
		a.autoTouch("focus")
	}
}

// loadTouch reads Touch ID's state when the unlock screen shows. It spawns
// the helper but calls the hub only for status, so it is not UI activity.
func (a *App) loadTouch() {
	if a.Touch == nil {
		return
	}
	gen := a.hubGen
	go func() {
		st := a.Touch.Status(context.Background())
		a.Update(func() {
			if gen != a.hubGen {
				return
			}
			a.touch = &st
			a.autoTouch("start")
		})
	}()
}

// autoTouch asks Touch ID by itself when model.AutoTouch says so.
func (a *App) autoTouch(trigger string) {
	if a.Touch != nil && model.AutoTouch(trigger, a.screen == model.ScreenLocked, a.touch, a.touchAsked, a.everReady, a.focused) {
		a.touchUnlock()
	}
}

// touchUnlock is one Touch ID unlock, asked for by the button or by autoTouch.
// A cancel shows nothing; an error shows on the unlock screen, and the status
// is read again because a reset deleted touchid.json.
func (a *App) touchUnlock() {
	if a.Touch == nil || a.touchBusy {
		return
	}
	a.touchBusy, a.touchAsked = true, true
	gen := a.hubGen
	go func() {
		res, err := a.Touch.Unlock(context.Background())
		a.Update(func() {
			a.touchBusy = false
			if err != nil {
				a.unlockErr = err.Error() // also after a hub restart: Interrupted says why
				a.loadTouch()
				return
			}
			if res.Cancelled {
				return
			}
			if gen == a.hubGen {
				a.unlockErr, a.lockReason = "", ""
				a.ranLocked = model.KeepRan(a.ranLocked, res.Reply.RanWhileLocked)
			}
			a.refresh()
		})
	}()
}

// openSettings opens Settings on the limit in force and, with Touch ID,
// on its state as the helper reports it now.
func (a *App) openSettings() {
	limit := a.status.SoftLockLimit
	open := func() {
		st := &settingsState{limit: limit, chosen: limit}
		if a.touch != nil {
			st.touch, st.touchOn = *a.touch, a.touch.Enabled
		}
		a.settings = st
	}
	if a.Touch == nil {
		open()
		return
	}
	gen := a.hubGen
	go func() {
		ts := a.Touch.Status(context.Background())
		a.Update(func() {
			if !a.ready(gen) || a.settings != nil {
				return
			}
			a.touch = &ts
			open()
		})
	}()
}

import (

// hidesOnClose is Electron's window.ts rule: on macOS closing the window
// hides it and the Dock icon, and the app, the hub and the unlocked vault run
// on behind the menu bar icon until Quit; elsewhere, and while quitting, a
// close closes.
func hidesOnClose(goos string, quitting bool) bool { return goos == "darwin" && !quitting }

// closeHook is the window's OnClose listener. quitting must be set by
// OnBeforeQuit: Quit closes every window, and a close that is always
// prevented would silently cancel Cmd+Q, the tray's Quit and SIGTERM.
func closeHook(goos string, quitting *atomic.Bool, hide func()) func(*mygo.CloseEvent) {
	return func(e *mygo.CloseEvent) {
		if hidesOnClose(goos, quitting.Load()) {
			e.PreventDefault()
			hide()
		}
	}
}

out=$app/out/sshgate.app
