# mygo desktop, slice 2 (terminals) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The native mygo app does what the Electron app's terminals do:
- many terminal tabs, with a tab strip (Hosts first), Reconnect, close, and the lifecycle texts the Electron app writes into a terminal;
- the unknown-host-key prompt (one at a time, Cancel default, Trust mouse-only behind the 500 ms guard) and the host-key mismatch dialog;
- Send to tab, for real;
- tabs across lock and hub restart;
- Cmd+Shift+A (Ctrl+Shift+A off macOS) from a terminal to the oldest request's reason, and Esc back.

Each piece carries the Electron renderer's rules and texts, with Go tests, and the terminal parts of the e2e specs `smoke`, `idle`, `keyboard` and `ui` are ported as flow tests against a real hub.

**Architecture:**
- **Layers.** Unchanged from slice 1: `hubapi` (typed door calls), `model` (pure rules with their vitest cases as table tests), `termconn` (a hub terminal as an `io.ReadWriteCloser`), `view` (the `App` controller and its screens).
- **Tabs.** `model.TabSet` is the port of `terminals.ts`. `view` keeps one `termTab` per tab id: a `*terminal.Terminal`, its `*termconn.Conn` and a `ui.Handle`. Only the active tab's `terminal.View` is built; hidden terminals keep reading their Conn.
- **Opening.** `App.Dial` (set by `main`, and by the flow tests) runs `termconn.Open` off the main thread. `App` makes the `terminal.Terminal` once the hub answers `open`. A `hostKeyUnknown` answer queues a prompt; Trust dials again with the same id and `trustHostKey`.
- **Exit texts.** `termconn.Conn` writes `[exited: …]` and `[input dropped: N bytes]` into its own read stream (never acked), so the terminal shows them where Electron shows them.

**Tech Stack:** Go 1.27.1 (`app/` module), mygo `ui` and `plugins/terminal` (fork commit `25387f1`), the existing `door`, `hubproc`, `termconn`, `hubapi`, `model`, `view` and `hubtest` packages, and `sshgate hub` (UI door protocol 12, MCP door).

## Review Focus

1. **A `term.open` answer that lands after its hub stopped, or after its tab closed.** It must not attach a terminal of the dead hub or reopen the tab; its hub terminal is closed. Covered by Task 4 (`TestOpenReplyAfterHubStopIsClosed`, `TestClosingAnOpeningTabClosesItsLateTerminal`).
2. **Remote-controlled text with control or bidi characters,** in an exit reason (from the remote, through the hub) or in host-key fields. A reason written into a terminal loses its controls; dialog fields show escapes, never raw runes. Covered by Task 3 (`TestExitEndsReadWithTheReason`) and Task 5 (`TestHostKeyDialogEscapesServerText`).
3. **Send to tab whose tab closes, never prints, or whose request is decided elsewhere while it waits.** Nothing is pasted for a decided request; no `decide` is sent; the request stays pending with an error, and its buttons work again. Covered by Task 6 (`TestSendToTabSkipsARequestDecidedMeanwhile`, `TestSendToTabFailsWhenItsTabCloses`, `TestSendToTabGivesUpAfterTheTimeout`).
4. **A host-key prompt waiting behind another prompt or across a lock.** The next prompt (and the same prompt after unlock) restarts the 500 ms Trust delay with Cancel focused; a closed tab drops its own prompt. Covered by Task 5 (`TestPromptsShowOneAtATimeAndAClosedTabDropsItsOwn`, `TestPromptSurvivesLockWithAFreshDelay`).
5. **Many tabs.** The strip scrolls; it never pushes AI or Lock out of the window. Covered by Task 4 (`TestManyTabsKeepLockReachable`).

## Decisions taken in this plan (controller rulings, on the spec)

1. **Hidden tabs.** Only the active tab's `terminal.View(c.Key("term-"+id), t)` is built. The emulator, scrollback and view state live on `*terminal.Terminal` (mygo.md §1, probed `TestHiddenKeepsState`), and the reader goroutine keeps parsing; `termconn` acks on read, so a hidden tab never stalls flow control. Keyed views do not carry focus across a switch (probed `TestFocusAcrossSwitch`), so each tab keeps a `ui.Handle`, and the app calls `Focus()` on activation, after a modal closes, after the AI column's `×`, after Esc in a reason, and on every entry into the ready screen (unlock). mygo never restores focus by itself (mygo.md gap 1).
2. **Tab strip.** A `ui.Row`: `Hosts`, then a `ui.ScrollHorizontal(c).Grow(1).MinWidth(0)` of tabs (each a button with the server name, `Reconnect` once exited, and `×`), then the AI button and Lock. Not `TabsBase`: its tabs are keyed by index only and `.Key` panics (mygo.md §5). The active button is `.Selected(true)` (accent colour, and assistive technology is told), which also closes slice 1's "tab bar shows no active page" minor. Probed in a scratch window of 800 DIPs with 30 tabs: Lock stays at x=748.
3. **Host key mismatch.** No host editor until slice 3, so the dialog shows both fingerprints, the hub's details and one `Close` (autofocused; Enter and Esc close it). Electron's `Open host editor` button is left out. The lead text is kept verbatim, though it names the host editor, which exists from slice 3 on. No re-pin, ever. The unknown-key prompt: one at a time (`model.HostKeyPrompts`), `Cancel` autofocused (Enter and Esc cancel), `Trust and connect` a `MouseButton` disabled for `AllowDelay` after the prompt shown changes (`model.ListChanges` keyed by `model.PromptKey`), and Trust retries `term.open` on the same tab id with `trustHostKey`.
4. **Send to tab is real**, in the Electron order (`App.tsx:329-333`): pick the server's most recently activated live tab, or open one; activate it; wait (local state only, at most 15 s) until it is open and the remote printed something; paste with `terminal.Paste` (no Enter is added; bracketed only when the remote enabled mode 2004, mygo.md §1 "Paste"); then `decide sent_to_tab`. It is disabled for a request with stdin (the hub refuses it: `broker.ErrSendToTabStdin`) and by the same timing guards as Allow; it stays a `MouseButton`. Slice 1's `TestStdinRequestDisablesSendToTabOnly` keeps its stdin case and now proves the button is disabled rather than absent. One change from Electron: a request decided elsewhere while its tab opened is not pasted.
5. **Cmd+Shift+A** (`ui.Super|ui.Shift` on darwin, `ui.Ctrl|ui.Shift` elsewhere) is a `Shortcut` on a `ui.Box` around the terminal view only. It is never window-level, because a window shortcut steals keys from the remote. The spec says "caught with the terminal's `OnKey`"; this ruling supersedes it. A container shortcut claims the key before the terminal sees it on every platform, and it is testable with `tt.Key` (probed `TestScopedShortcut`; re-probed in the slice layout: `hits 2` for `tt.Key` and `tt.KeyAt`). It opens the AI column if collapsed and focuses the oldest request's reason field; the focus request waits for the field's first build. Esc in a reason field focuses the active tab's terminal; with no terminal tab active it does nothing. On a layout that does not type an A, mygo matches the chord by key position (`ui/input.go` `keyDownPhysical`), which ports the vitest "non-Latin layout" row.
6. **Terminal texts.** Electron's texts written into a terminal are ported verbatim:
   - `[exited: <reason>]`, with reason `code N` when the hub gave none;
   - `[input dropped: N bytes]`;
   - `hub restarted`.
   `termconn.Conn` queues them as output of its own that `Read` returns without a `term.ack`. mygo then appends its own dim `[Disconnected]` on EOF (`terminal.go` `ended()`), which the fork does not let us turn off; both lines show. A tab whose open failed has no terminal (one is made only after the hub says `open`), so its page shows `[exited: open failed: <message>]` as text. `Reconnect` closes the tab and opens a new one at the end of the strip.
7. **Lock and hub restart.** Tabs survive a lock: the lock screen replaces the ready screen, the terminals stay connected and keep reading, and the active terminal is focused again after unlock. A hub that stops ends every live tab: `conn.End("hub restarted")` writes the text and sends no `term.close` to the dead hub. The tabs stay, with Reconnect, and nothing is reattached after the restart. This replaces slice 1's M4 fix ("clear the single terminal, page home").
8. **Terminal size: already wired by mygo.** The terminal calls `Conn.Resize(cols, rows)` whenever its view lays out at a new size (`terminal.go` `resize`→`resizeConn`); `termconn` clamps and sends `term.resize`. Probed in the slice layout: a view of 420×439 DIPs sent `51x26` on its first frame. So `term.open` keeps 24×80, the hub is told the real size on the first frame that shows the tab, and a tab opened in the background runs at 24×80 until it is first shown (mygo.md gap 5). No hidden tab is resized, since its view is not built.
9. **Slice-1 carries.** Every `term.open` reply is checked against the hub generation and against its tab still being open; a stale reply closes its terminal (Review Focus 1). The open is bounded by `callTimeout` (60 s), so a hung hub fails the tab with `hub did not answer in 60 s` and termconn closes the late hub terminal. Slice-0 minors stay deferred: `door.write` ignores ctx, `sc.Err` is dropped, `tailWriter` is unbounded, `waitWrites` is time-based.
10. **Unpinned host in tests.** Flow tests unlock, then call `servers.forgetHostKey` on `box` through the new `hubapi.ForgetHostKey`, as test-side setup only (the UI for it is slice 3). This replaces the spec's "tests that need an unpinned host write their own store": the app module cannot import `internal/config` to sign one, and the hub's own call needs no change to sshtestd. A real-hub `hostKeyMismatch` is not reachable with sshtestd (its host key is fresh per process), so the mismatch dialog is covered by fake-door unit tests only.
11. **Activity rule unchanged.** No hub call on a timer. The `user: true` rule and its tests stay. This plan adds the exact 1000 ms boundary row and a flow test that the idle lock fires with a terminal tab open. Send to tab's `terminal.Paste` marks nothing, since the `decide` it sends already counts.

Added in this plan:

12. **Accessible names.** A host card is labelled `Open <name>`, a tab's `×` is labelled `Close tab` (tooltip `Close`), and a terminal view is labelled `Terminal <name>`. Electron's names collide here: the card and the tab are both "box", and the tab's "Close" is the same name as the mismatch dialog's `Close`. `tt.Find` takes the first match.
13. **Not ported, on purpose.**
    - The Audit tab button: slice 6. `TabSet` still ports `ShowAudit`/`AuditTab` with its vitest case.
    - Files and tunnels tab kinds, with `findKind` and their two vitest cases: slices 4 and 5.
    - The resize `Debouncer`: mygo sends the size from layout.
    - `term.closeAll`: there is no renderer crash to recover from.
    - Electron counting `mousedown` in a terminal as input: a click alone writes nothing.
14. **Remote title and notifications.** `OnTitle`, `OnBell` and `OnNotify` stay unset. The tab label is the server name only, as in Electron, which meets the spec's rule that a remote title never becomes the window title or a notification.
15. **Links.** `OpenLink` keeps refusing every link, as the Electron app opens none. The spec's "http/https after a confirm" is in no slice row and has no Electron texts to port. It is deferred, and `term.go`'s comment now says so instead of "the confirm comes in slice 2".
16. **Send to tab needs the remote's first output** (Electron's `sawOutput`), from `Conn.Output()`. sshtestd prints nothing until it echoes input, so the flow test types one key into the new tab first.
17. **The `hostKeyUnknown` and `hostKeyMismatch` details are `hubapi.HostKey`**, the type of a UI-door result, so `model` (the prompt queue) and `termconn` (`OpenError.Key`) share it without an import cycle.

```go
// HostKey is a term.open result other than "open". hostKeyUnknown carries
// Fingerprint, KeyType and KnownHosts ("match", "different" or "absent", a
// hint from ~/.ssh/known_hosts, never pinned from); hostKeyMismatch carries

type HostKey struct {
	Status      string `json:"status"`
	Server      string `json:"server"`
	Host        string `json:"host"`
	Port        int    `json:"port"`
	User        string `json:"user"`
	Fingerprint string `json:"fingerprint,omitempty"`
	KeyType     string `json:"keyType,omitempty"`
	KnownHosts  string `json:"knownHosts,omitempty"`
	Pinned      string `json:"pinned,omitempty"`
	Presented   string `json:"presented,omitempty"`
}

// Trust is term.open's trustHostKey: the key the person checked, which the
// hub pins once a dial pinned to exactly it succeeds.
type Trust struct {
	Fingerprint string `json:"fingerprint"`
	KeyType     string `json:"keyType"`
}
```

```go
	ExitReason string

// Hosts home), and the activation order closing a tab falls back on.
type TabSet struct {
	Tabs   []Tab
	Active string
	order  []string
	next   int
}

// Open adds a terminal tab at the end and activates it. Ids are "t1",
// "t2", …: within the hub's id rule, and never reused while the app runs.
func (s *TabSet) Open(server string) string {
	s.next++
	id := fmt.Sprintf("t%d", s.next)
	s.Tabs = append(s.Tabs, Tab{ID: id, Server: server, State: "opening"})
	s.Activate(id)
	return id
}

func (s *TabSet) find(id string) *Tab {
	for i := range s.Tabs {
		if s.Tabs[i].ID == id {
			return &s.Tabs[i]
		}
	}
	return nil
}

// Get returns the tab id, if it is open in the strip.
func (s *TabSet) Get(id string) (Tab, bool) {
	if t := s.find(id); t != nil {
		return *t, true
	}
	return Tab{}, false
}

// Opened moves an opening tab to open; any other state stays.
func (s *TabSet) Opened(id string) {
	if t := s.find(id); t != nil && t.State == "opening" {
		t.State = "open"
	}
}

func (s *TabSet) Output(id string) {
	if t := s.find(id); t != nil {
		t.SawOutput = true
	}
}

// Exited ends a tab; it stays in the strip with its reason.
func (s *TabSet) Exited(id, reason string) {
	if t := s.find(id); t != nil {
		t.State, t.ExitReason = "exited", reason
	}
}

func (s *TabSet) Activate(id string) {
	s.Active = id
	s.order = append(slices.DeleteFunc(s.order, func(o string) bool { return o == id }), id)
}

func (s *TabSet) ShowHome()  { s.Active = "" }
func (s *TabSet) ShowAudit() { s.Active = AuditTab }

// tab in activation order (or the Hosts home) become active.
func (s *TabSet) Close(id string) {
	s.Tabs = slices.DeleteFunc(s.Tabs, func(t Tab) bool { return t.ID == id })
	s.order = slices.DeleteFunc(s.order, func(o string) bool { return o == id })
	if s.Active == id {
		s.Active = ""
		if n := len(s.order); n > 0 {
			s.Active = s.order[n-1]
		}
	}
}

// exited (an opening one counts), or "".
func (s *TabSet) MostRecentFor(server string) string {
	for i := len(s.order) - 1; i >= 0; i-- {
		if t := s.find(s.order[i]); t != nil && t.Server == server && t.State != "exited" {
			return t.ID
		}
	}
	return ""
}

	n := 0
	for _, t := range s.Tabs {
		if t.Server == server && t.State != "exited" {

		}
```

```go
type HostKeyPrompt struct {

	Key hubapi.HostKey
}

// HostKeyPrompts shows host-key prompts one at a time, oldest first,
// across every tab (desktop/src/renderer/hostkeys.ts).
type HostKeyPrompts struct{ q []HostKeyPrompt }

func (p *HostKeyPrompts) Ask(id string, k hubapi.HostKey) {
	p.q = append(p.q, HostKeyPrompt{ID: id, Key: k})
}

// Current is the prompt shown.
func (p *HostKeyPrompts) Current() (HostKeyPrompt, bool) {
	if len(p.q) == 0 {
		return HostKeyPrompt{}, false
	}
	return p.q[0], true
}

// Answer takes the shown prompt off the queue and returns it.
func (p *HostKeyPrompts) Answer() (HostKeyPrompt, bool) {
	c, ok := p.Current()
	if ok {
		p.q = p.q[1:]
	}
	return c, ok
}

// Drop removes a tab's prompt wherever it waits, and reports whether it had one.
func (p *HostKeyPrompts) Drop(id string) bool {
	for i, x := range p.q {
		if x.ID == id {
			p.q = append(p.q[:i:i], p.q[i+1:]...)
			return true
		}
	}
	return false
}

// PromptKey changes whenever the prompt shown changes, which restarts the
// Trust delay.
func PromptKey(p HostKeyPrompt, ok bool) string {
	if !ok {
		return ""
	}
	return p.ID + "|" + p.Key.Fingerprint
}

// TrustEnabled: Trust waits AllowDelay after the prompt shown last changed.
func TrustEnabled(changedAt, now time.Time) bool { return now.Sub(changedAt) >= AllowDelay }
```

```go
// write still counts as the user's, for the hub's idle lock (Electron's
// USER_INPUT_WINDOW_MS).
const UserWindow = time.Second

const maxDim = 1000 // internal/hub/term.go maxTermDim

// Door is the part of the UI door client a Conn uses.
type Door interface {
	Call(ctx context.Context, method string, params, result any) error
	Notify(method string, params any) error
}

// OpenError is a term.open the hub answered with another status than
// "open": hostKeyUnknown or hostKeyMismatch, with the hub's details in Key.
type OpenError struct {
	Status string
	Key    hubapi.HostKey
}

func (e *OpenError) Error() string { return "terminal not opened: " + e.Status }

// chunk is output for the terminal: from the hub (acked once read), or a
// line the app writes itself (never acked: the hub did not send it).
type chunk struct {
	b     []byte
	local bool
}

// Conn is a hub terminal as an io.ReadWriteCloser for terminal.Options.Conn.
// Read returns what the hub sent and acks it, so the hub's reader stalls at
// its high-water mark while the terminal parses: that is the backpressure.
type Conn struct {
	d   Door
	m   *Mux
	id  string
	now func() time.Time
	out chan struct{} // closed at the hub's first output

	mu        sync.Mutex
	queue     []chunk
	buf       []byte
	bufLocal  bool
	ended     bool
	closed    bool
	sawOutput bool
	reason    string
	drop      int
	lastUser  time.Time
	ready     chan struct{} // a token when queue or ended changed
}

// trust is nil, or the key the person accepted on a hostKeyUnknown answer,
// sent with the same id (the hub released it).
func Open(ctx context.Context, d Door, m *Mux, id, server string, rows, cols int, trust *hubapi.Trust) (*Conn, error) {
	c := &Conn{d: d, m: m, id: id, now: time.Now, out: make(chan struct{}), ready: make(chan struct{}, 1)}
	if !m.add(c) { // before term.open: data may arrive before its reply
		return nil, errors.New("terminal id already in use")
	}
	p := map[string]any{"id": id, "server": server, "rows": clamp(rows), "cols": clamp(cols)}
	if trust != nil {
		p["trustHostKey"] = trust
	}
	var res json.RawMessage
	err := d.Call(ctx, "term.open", p, &res)
	if err != nil {
		m.remove(id)
		var he *door.Error
		if !errors.As(err, &he) {
			// No hub answer (ctx ended, door closed): the hub may still have opened it.
			c.hubClose()
		}
		return nil, err
	}
	var k hubapi.HostKey
	json.Unmarshal(res, &k)
	if k.Status != "open" {
		m.remove(id)
		return nil, &OpenError{Status: k.Status, Key: k}
	}
	return c, nil
}

func clamp(n int) int { return max(1, min(n, maxDim)) }

// printable drops C0, DEL and C1 controls, so a reason the hub relays from
// the remote cannot drive the terminal it is written into.
func printable(s string) string {
	return strings.Map(func(r rune) rune {
		if r < 0x20 || r >= 0x7f && r <= 0x9f {
			return -1
		}
		return r
	}, s)
}

func (c *Conn) signal() {
	select {
	case c.ready <- struct{}{}:
	default:
	}
}

func (c *Conn) push(b []byte) {
	c.mu.Lock()
	if !c.ended {
		c.queue = append(c.queue, chunk{b: b})
		if !c.sawOutput {
			c.sawOutput = true
			close(c.out)
		}
	}
	c.mu.Unlock()
	c.signal()
}

// Output is closed once the hub sent the first output: the remote is up.
func (c *Conn) Output() <-chan struct{} { return c.out }

// exit ends the terminal once, after what the hub sent, with the reason
// written into it as the Electron app writes it.
func (c *Conn) exit(reason string) {
	c.mu.Lock()
	if !c.ended {
		c.ended, c.reason = true, reason
		c.queue = append(c.queue, chunk{b: []byte("\r\n[exited: " + printable(reason) + "]\r\n"), local: true})
	}
	c.mu.Unlock()
	c.signal()
}

// End ends the terminal without asking the hub, as when the hub stopped.
func (c *Conn) End(reason string) {
	c.exit(reason)
	c.m.remove(c.id)
}

func (c *Conn) dropped(n int) {
	c.mu.Lock()
	c.drop += n
	if !c.ended {
		c.queue = append(c.queue, chunk{b: fmt.Appendf(nil, "\r\n[input dropped: %d bytes]\r\n", n), local: true})
	}
	c.mu.Unlock()
	c.signal()
}

// Dropped is how many bytes of input the hub dropped (its queue was full).
func (c *Conn) Dropped() int { c.mu.Lock(); defer c.mu.Unlock(); return c.drop }

// ExitReason is the reason the terminal ended with, empty before it.
func (c *Conn) ExitReason() string { c.mu.Lock(); defer c.mu.Unlock(); return c.reason }

func (c *Conn) Read(p []byte) (int, error) {
	for {
		c.mu.Lock()
		if len(c.buf) == 0 && len(c.queue) > 0 {
			c.buf, c.bufLocal, c.queue = c.queue[0].b, c.queue[0].local, c.queue[1:]
		}
		if len(c.buf) > 0 {
			n := copy(p, c.buf)
			c.buf = c.buf[n:]
			local := c.bufLocal
			c.mu.Unlock()
			if !local {
				c.d.Notify("term.ack", map[string]any{"id": c.id, "n": n})
			}
			return n, nil
		}
		if c.ended {
			c.mu.Unlock()
			return 0, io.EOF
		}
		c.mu.Unlock()
		<-c.ready
	}
}

// MarkUser records a real key, paste or input-method commit: writes in
// the next UserWindow count as the user's.
func (c *Conn) MarkUser() { c.mu.Lock(); c.lastUser = c.now(); c.mu.Unlock() }

// Write sends to the hub. It never fails while the tab is open: mygo's
// terminal closes its input for good on a write error. A full hub queue
// comes back as term.dropped instead.
func (c *Conn) Write(p []byte) (int, error) {
	c.mu.Lock()
	closed := c.closed
	user := !c.lastUser.IsZero() && c.now().Sub(c.lastUser) < UserWindow
	c.mu.Unlock()
	if closed {
		return 0, io.ErrClosedPipe
	}
	// An error means the hub is gone; the supervisor reports that.
	_ = c.d.Notify("term.write", map[string]any{"id": c.id, "data": p, "user": user})
	return len(p), nil
}

// Resize is mygo's (cols, rows); the hub takes rows and cols, 1..1000.
func (c *Conn) Resize(cols, rows int) error {
	c.d.Notify("term.resize", map[string]any{"id": c.id, "rows": clamp(rows), "cols": clamp(cols)})
	return nil
}

// Close ends the hub terminal once. One that already ended (term.exit, or
// End) is gone from the hub, so nothing is sent.
func (c *Conn) Close() error {
	c.mu.Lock()
	if c.closed {
		c.mu.Unlock()
		return nil
	}
	ended := c.ended
	c.closed, c.ended = true, true
	c.mu.Unlock()
	c.m.remove(c.id)
	c.signal()
	if !ended {
		c.hubClose()
	}
	return nil
}

// hubClose ends the hub terminal. term.close is request-only on the hub, so
// a notification would be ignored. Best effort, never under c.mu.
func (c *Conn) hubClose() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	_ = c.d.Call(ctx, "term.close", map[string]any{"id": c.id}, nil)
}
```

```go
// dial runs term.open off the main thread; the reply comes back through
// Update, where opened checks that its hub and its tab are still there.
func (a *App) dial(id, server string, trust *hubapi.Trust) {
	if a.Dial == nil {
		a.fail(id, "the hub is not running")
		return
	}
	gen := a.hubGen
	go func() {
		ctx, cancel := context.WithTimeout(context.Background(), callTimeout)
		conn, err := a.Dial(ctx, id, server, trust)
		cancel()
		if errors.Is(err, context.DeadlineExceeded) {
			err = fmt.Errorf("hub did not answer in %d s", int(callTimeout.Seconds()))
		}
		a.Update(func() { a.opened(gen, id, conn, err) })
	}()
}

func (a *App) opened(gen int, id string, conn *termconn.Conn, err error) {
	t, ok := a.tabs.Get(id)
	if gen != a.hubGen || !ok || t.State != "opening" {
		if conn != nil {
			go conn.Close() // its tab closed, or its hub stopped, while it opened
		}
		return
	}
	if err != nil {
		a.fail(id, err.Error())
		return
	}
	term, err := terminal.New(TerminalOptions(conn, func() { a.Update(func() { a.exited(id, conn.ExitReason()) }) }))
	if err != nil {
		go conn.Close()
		a.fail(id, err.Error())
		return
	}
	tab := a.terms[id]
	tab.term, tab.conn = term, conn
	a.tabs.Opened(id)
	if a.tabs.Active == id {
		tab.h.Focus()
	}
}

// fail ends a tab whose open failed; it has no terminal, so its page
// shows the reason.
func (a *App) fail(id, msg string) { a.exited(id, "open failed: "+msg) }

// exited marks a tab ended; the terminal already shows why (termconn).
func (a *App) exited(id, reason string) {
	if t, ok := a.tabs.Get(id); !ok || t.State == "exited" {
		return
	}
	a.tabs.Exited(id, reason)
}

func (a *App) activate(id string) {
	a.tabs.Activate(id)
	a.focusActive()
}

// focusActive focuses the active tab's terminal, if it has one.
func (a *App) focusActive() {
	if t := a.terms[a.tabs.Active]; t != nil && t.term != nil {
		t.h.Focus()
	}
}

// closeTab removes a tab; its terminal closes off the main thread
// (term.close may wait up to 5 s on a hung hub). An opening tab's late
// reply is closed by opened.
func (a *App) closeTab(id string) {
	a.tabs.Close(id)
	if t := a.terms[id]; t != nil && t.term != nil {
		go t.term.Close()
	}
	delete(a.terms, id)
	a.focusActive()
}

// endTabs ends every live tab when the hub stops: its terminals died with
// it. The tabs stay, showing why, with Reconnect.
func (a *App) endTabs() {
	for _, t := range a.tabs.Tabs {
		if t.State == "exited" {
			continue
		}
		a.tabs.Exited(t.ID, "hub restarted")
		if tt := a.terms[t.ID]; tt != nil && tt.conn != nil {
			tt.conn.End("hub restarted")
		}
	}
}

// buildTabStrip draws one button per tab, with Reconnect once it exited and
```

```go
package view

import (
	"time"

	"github.com/lang315/sshgate/app/hubapi"
```

```go
// sendReadyTimeout is how long Send to tab waits for its tab to open and
// print (Electron's waitReady). A var so tests can shorten it.
var sendReadyTimeout = 15 * time.Second

// pendingSend is a Send to tab waiting for its tab.
type pendingSend struct{ req, tab, command string }

// sendToTab pastes a request's command into its server's most recent tab,
// or a new one, once that tab is open and the remote printed something,
// then decides sent_to_tab (the Electron order: paste, then decide).
// Nothing runs: no Enter follows the paste.
func (a *App) sendToTab(r hubapi.Request) {
	if a.itemBusy[r.ID] {
		return
	}
	if r.Stdin != "" { // the button is disabled; the hub refuses it too
		a.itemErr[r.ID] = "Send to tab is not available for a command with stdin"
		return
	}
	id := a.tabs.MostRecentFor(r.Server)
	if id == "" {
		id = a.openTab(r.Server)
	} else {
		a.activate(id)
	}
	a.itemBusy[r.ID], a.itemErr[r.ID] = true, ""
	a.sends = append(a.sends, pendingSend{req: r.ID, tab: id, command: r.Command})
	req := r.ID
	time.AfterFunc(sendReadyTimeout, func() { a.Update(func() { a.endSend(req, "terminal did not become ready") }) })
	a.flushSends(id)
}

// flushSends pastes or fails the sends waiting for tab id. A request
// decided elsewhere meanwhile is not pasted.
func (a *App) flushSends(id string) {
	t, ok := a.tabs.Get(id)
	var keep []pendingSend
	for _, s := range a.sends {
		switch {
		case s.tab != id:
			keep = append(keep, s)
		case !ok || t.State == "exited":
			delete(a.itemBusy, s.req)
			a.itemErr[s.req] = "terminal closed"
		case t.State == "open" && t.SawOutput:
			delete(a.itemBusy, s.req)
			if a.waiting(s.req) {
				a.terms[id].term.Paste(s.command)
				a.decide(s.req, hubapi.SentToTab, "")
			}
		default:
			keep = append(keep, s)
		}
	}
	a.sends = keep
}

// endSend fails a send still waiting.
func (a *App) endSend(req, msg string) {
	for i, s := range a.sends {
		if s.req == req {
			a.sends = append(a.sends[:i:i], a.sends[i+1:]...)
			delete(a.itemBusy, req)
			a.itemErr[req] = msg
			return
		}
	}
}

func (a *App) waiting(req string) bool {
	for _, it := range a.items {
		if it.Request.ID == req {
			return true
		}
	}
	return false
}
```

```go
// countDoor is the door terminals use, counting the bytes of term.write
// sent as the user's (the idle lock counts only those).
type countDoor struct {
	termconn.Door
	mu   sync.Mutex
	user int
}

func (d *countDoor) Notify(method string, params any) error {
	if p, ok := params.(map[string]any); ok && method == "term.write" && p["user"] == true {
		d.mu.Lock()

		d.mu.Unlock()

}
```

```go
func (f *flowT) auditedConfig(action string) {

			}
		}
		return false
	}, "box's "+action+" config record")
```
